分類 → 條目 → 子主題
分類索引
看look / l / ls
觀察位置或活物。看活物額外顯示其當前戰鬥數值（攻/敏/防/魔階/生命）。
前往goto / path
沿最短路徑自動移動；path <地點> 只看路不走；無參顯示当前路線。
說明help / ?
無參顯示分類索引，支援 主題/子主題/次主題… 多層查詢。
rest / sleep / wait時間跳躍
活動戰鬥或同室有存活魔物時會被安全門拒絕。
engage攻擊 / 戰鬥
與敵對魔物開戰（非戰鬥且當地有存活敵方時）。
cast施法
cast <技法>[@威力][=代號]；戰鬥內可用 =all-enemies/all-allies/all；威力 1/4、1/2、1、2、4 限元素主宰。
combat actionscombat 動作
列出可用技法（分類分群、性愛技法獨立）與目標代號，是施放前參照表。
combat forfeit投降
結束戰鬥／公會考核（進行中才可用；需二次確認）。
guild listguild 任務
查看任務板上符合你階級的委託。
guild accept / turnin / abandon接取 / 回報 / 放棄
接取 <definition_key>；回報領一次報酬；放棄需確認。
guild examguild 考核
申請下一階級考核，開啟模擬戰。需當地考核官且功績達門檻。
shop stock / buy / sell商店
看庫存與買賣價、買／賣 [數量]。商店有營業時段與日程門。
inventory背包 / inv
查看錢包（整數銅）與背包清單。
talk / 交談
與 NPC 交談；talk <npc> <關鍵詞>。日程門可能拒絕。
invite / leave邀請 / 解散
邀 NPC 入隊（最多 4）；解散不影響親密度。
