# 伊洛瑟恩 MUD 文件

本文件網站提供伊洛瑟恩 MUD 的遊戲主持人操作說明。內容依現行程式碼與已實作的規格撰寫，適用於建立角色、設計確定性任務、設定公會報酬，以及啟動與驗證遊戲世界。

遊戲是單人制、成人題材的 AI 輔助 MUD。世界的戰鬥、任務、金錢與時間由確定性規則處理；LLM 與圖像服務離線時，既有遊戲流程仍須可遊玩。所有角色均為成年人，這項限制由匯入驗證器強制執行。

## 從這裡開始

若要安排世界內容，先閱讀「[總覽與工作原則](/gm/overview)」。接著依需求選擇「[角色建立與匯入](/gm/characters)」或「[任務撰寫與上架](/gm/quests)」。完成異動後，請依「[維運與驗證](/gm/operations)」執行驗證。

## 預覽文件網站

Docsify 需透過 HTTP 伺服器載入 Markdown 檔。於專案根目錄執行下列命令，然後在瀏覽器開啟 `http://localhost:3000`。

```sh
uv run --locked python -m http.server --directory docs 3000
```

## 文件範圍

文件描述的是目前已提供的作業途徑。角色匯入器可建立 `NPC` 或 `PlayerCharacter` 物件；後者不會自動建立或綁定 Evennia 帳號。任務定義與公會任務板目前由版本控制中的 Python 與 YAML 資料登錄，尚未提供遊戲內的通用任務編輯介面。

請把角色卡、任務定義與規則書變更納入程式碼審查。不要直接修改角色的任務紀錄、錢包、庫存或戰鬥數值，這些持久狀態須經由其所屬的確定性 API 更新。
