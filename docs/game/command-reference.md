# 遊戲指令參考

本文是玩家在遊戲中可直接輸入的指令參考，涵蓋三層輸入介面：本專案自行撰寫的玩家指令（含角色建立指令 `character`）、本地化的 Evennia 預設指令（zh-tw 主鍵，保留英文別名）、XYZGrid 指令（`@teleport`、`@open` 保留英文，`goto`/`map` 由「前往」/「地圖」取代），以及保留為英文的 Evennia 預設角色與帳號指令。每條指令的別名、語法與情境都受 `tests/test_command_docs.py` 的契約測試保護，任何指令的增刪或行為異動都必須在同一個變更中更新本文。

- 情境標示「管理員」的指令需要 `Developer` 權限（目前為 `art` 指令家族）。
- 情境標示「建造者權限」的指令需要 `Builder` 權限（`地圖`、`@teleport`、`@open`）。
- 登入前的指令（`connect`、`create`、`login`）不屬於遊戲內輸入，完整說明請見 [Evennia 官方文件](https://evennia.com/docs/latest/Components/Commands.html)。
- Evennia 預設指令的完整細節請見頁尾索引表的 Evennia 官方文件連結。

## 技能施放

### cast

| 項目 | 內容 |
| --- | --- |
| 指令 | `cast` |
| 別名 | `施法` |
| 語法 | `cast <skill_key>[@<scale>][=<target_key>]` |
| 情境 | 一般（戰鬥內外皆可施放技能） |
| 說明 | 施放指定的技能；在戰鬥中可指定目標代號（`cast <技能>=<代號>` 或 `cast <技能>=<代號1,代號2>`）。`<scale>` 為可選的威力比例（`1/4`、`1/2`、`1`、`2`、`4`，預設 `1`），僅持有對應屬性主宰（`<element>_mastery`）的角色可自由調整該屬性法術的威力與 MP 消耗（例如 `cast wind_blade@2=wolf` 以兩倍消耗造成兩倍威力）；其餘使用會被拒絕。性愛技能同樣以 `cast <skill_key>[@<scale>][=<target_key>]` 語法施放；部分基礎技能起始可用，其餘隨遊玩解鎖。 |

性愛技能是普通技能的一種，各自依解鎖條件取得：部分基礎技能起始即可使用，其餘須在遊玩中達成對應條件後解鎖。已持有者可透過 `combat actions` 依類別檢視，性愛技能再依線別分組。

神之秘法系的性愛技能不設計數解鎖門檻，但僅限種族符合資格的施法者使用；入門技能 `divine_sexual_arts` 僅於建立角色時授予種族符合資格的角色。

對可抵抗的性愛技能，目標會獲得一次抵抗判定，戰鬥內外皆然：抵抗成功的目標不受該次施放的目標效果影響，施放本身仍消耗時間，並依技能設定支付資源成本（若有）；抵抗失敗則對目標正常執行。施法者的自身效果（如自身快感）不因抵抗結果而改變。對同伴 NPC 強迫施放（抵抗失敗）會扣減好感度，可能使同伴自動離開隊伍，發生時施法者會收到通知。

興奮、高潮與露出狀態在作用期間，會以一般戰鬥狀態標籤顯示：高度興奮敏捷與準度減損、高潮進行中鎖定行動、高露出防禦減損。
