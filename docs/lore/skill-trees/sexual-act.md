# 情慾秘術：系統分類定位

情慾秘術是獨立於元素魔法與神之秘法之外的技能分類，與光明教會信仰體系、精靈族生理特質緊密相關。本頁只說明它在整個技能體系裡的**分類位置與解鎖骨架**，不展開具體招式內容——實際的招式設計、敘事描寫與數值細節由角色設定與劇情文件驅動，屬於另一層工作，不在世界觀機制文件的範圍內。

## 分類位置

| 項目 | 說明 |
| --- | --- |
| 對應分類 | `SkillCategory.SEXUAL_ACT` |
| 資源與判定 | 與魔法系譜的「熟練度／MP」是不同的軸線，機制上連結到角色間的好感度、狀態效果與獨立的情慾秘術計數器，不套用本分類其他系譜使用的 `SkillPrerequisite` 熟練度公式 |
| 解鎖階梯 | 由角色自身的情慾秘術計數器把關（登記於 `SEXUAL_ACT_REGISTRY`），不是「使用次數換算等級」的系譜樹形狀 |
| 神性門檻 | 頂點技能（性魔法主宰、神之秘法：性愛系統）與 [神之秘法系譜樹](/lore/skill-trees/divine-mystery) 共用同一道「神性」門檻，只有精靈族能夠觸及 |

## 與神之秘法的關係

情慾秘術之所以獨立分類而非併入神之秘法，是因為它的效果聚焦於角色互動與感官狀態，而非「直接干涉世界之理」；但它的最高階技藝仍然要求神性，這代表光明教會的性愛核心教義不只是風俗描寫，而是有實際魔法效力作為信仰根基——這一點在 [魔法技能體系](/lore/magic-system) 第 10 節已有說明，本頁不重複展開。

## 本頁刻意不涵蓋的內容

- 具體招式名稱、效果描述、數值。
- 任何角色的個人情慾秘術能力清單。
- 情慾秘術計數器的門檻數值與判定公式細節。

這些內容如果要系譜化，應該由熟悉 `world/skills/sexual_acts/` 現行實作與角色劇情設定的人員另外處理，不適合併入本輪的魔法／武藝系譜設計工作。
