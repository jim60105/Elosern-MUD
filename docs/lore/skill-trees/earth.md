# 土屬性系譜樹

土的核心是「限制敵人的自由」，系譜樹分成防禦與控制兩條根：一條把自己與盟友磨成磐石，一條把戰場變成敵人無法脫身的陷阱。

## 樹狀結構

```
【防禦路線】                                                    ┐
硬化肌膚 hardened_skin（根）                                    │
└─ 岩甲術 stone_armor（Lv.3）── 分支點                          │
    ├─ 磐石壁壘 bedrock_bastion（Lv.3）                         │
    │   └─ 大地庇護 earthen_ward（Lv.5，分支終點）               │ 匯合
    └─ 荊棘反甲 thorned_carapace（Lv.3，分支終點）                │
                                                                │
【控制路線】                                                    │
石礫術 stone_shard（根）                                        │
└─ 沙塵術 dust_veil（Lv.3）── 分支點                             │
    ├─ 地縛術 earth_bind（Lv.3）                                │
    │   └─ 地震術 earthquake（Lv.5）                            │
    │       └─ 山嶽崩落 mountain_collapse（Lv.8）───────────────┤
    └─ 岩壁崩落 rockslide（Lv.3）                                │
        └─ 地脈崩裂 fault_rupture（Lv.8）                        │
            └─ 大地審判 earths_judgment（Lv.8）──────────────────┤
                                                                ▼
                                              大地神格 earthen_apotheosis
```

前置條件的 `Lv.N` 換算成實際施放次數請套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式：次數 = `50 × N ÷（種族學習倍率 × 屬性親和倍率）`，無條件進位。

## 節點設計說明

- **岩甲術的雙分支**：磐石壁壘走向全隊防禦的持久戰路線，荊棘反甲走向「不閃不躲、以傷還傷」的近戰坦克路線，兩者是防禦哲學的兩種極端。
- **沙塵術的雙分支**：地縛術路線專精大範圍束縛與最終的毀滅級地震，岩壁崩落路線專精單體處決，呼應土屬性「控制與傷害不可分割」的設計核心。
- **大地神格**：唯一同時具備範圍毀滅與束縛控制的節點，代表大地本身甦醒、不留任何人脫身的極限型態。
