# 土屬性系譜樹

土的獨佔動詞是**地形與護**：固定防禦 buff 的全遊戲唯一供應商，加上召出「困難地形標記」的地形線（見 [總覽](/lore/skill-trees/index) §4 配給制）。土讓腳下的地變成敵人；所有 +N 防禦只從土樹與其附魔產出。

## 樹狀結構

```
【護甲路線】                                                    ┐
硬化肌膚 hardened_skin（根）                                    │
└─ 岩甲術 stone_armor（Lv.3）── 分支點                          │
    ├─ 磐石壁壘 bedrock_bastion（Lv.3）                         │
    │   └─ 大地庇護 earthen_ward（Lv.5，分支終點）               │ 匯合
    └─ 荊棘反甲 thorned_carapace（Lv.3，分支終點）                │
                                                                │
【地形路線】                                                    │
石礫術 stone_shard（根）                                        │
└─ 沙塵術 dust_veil（Lv.3）── 分支點                             │
    ├─ 地裂術 ground_fissure（Lv.3）                            │
    │   └─ 地震術 earthquake（Lv.5）                            │
    │       └─ 山嶽崩落 mountain_collapse（Lv.8）───────────────┤
    └─ 岩壁崩落 rockslide（Lv.3）                                │
        └─ 地脈崩裂 fault_rupture（Lv.8）                        │
            └─ 大地審判 earths_judgment（Lv.8）──────────────────┤
                                                                ▼
                                              大地神格 earthen_apotheosis
```

前置條件的 `Lv.N` 換算成實際施放次數請套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式，次數 = `50 × N ÷（種族學習倍率 × 屬性親和倍率）`，無條件進位。

## 節點設計說明

- **岩甲術的雙分支**：磐石壁壘走向全隊防禦的持久戰路線，荊棘反甲走向「不閃不躲、以傷還傷」的近戰坦克路線，兩者是護的哲學的兩種極端。全遊戲所有固定防禦 buff 只從這條根產出，想要防禦數字，來土樹買；土的護與土的不動是同一個身體觀。
- **沙塵術的雙分支**：地裂術路線專精大範圍地形標記與最終的毀滅級地震，岩壁崩落路線專精單體處決，呼應土「地形與傷害不可分割」的設計核心。地裂給的是裂縫標記與冰階梯第一 rung，真正的束縛／定身由冰樹執行：土讓腳下變壞，冰讓身體停下。
- **大地神格**：唯一以覆蓋全場的地形標記收尾的神格節點，代表大地本身甦醒、整片戰場都變成土的領土的極限型態。
