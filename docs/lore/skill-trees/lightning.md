# 雷屬性系譜樹

雷以「先制」與「連續行動」為核心：一條根走向讓自己更快、更早出手，一條根走向純粹的過載爆發與麻痺控制。

## 樹狀結構

```
【先制路線】
靜電護體 static_ward（根）
└─ 雷光連閃 lightning_flicker（Lv.3）
    └─ 雷霆連擊 thunder_combo（Lv.3）── 分支點
        ├─ 雷神之速 thunder_gods_haste（Lv.5）
        │   └─ 審判雷霆 judgement_thunder（Lv.8）───────────────┐
        └─ 疾雷連擊·壞 chain_break_strike（Lv.5，分支終點）      │ 匯合
                                                                │
【過載路線】                                                    │
電擊術 spark_shock（根）── 分支點                               │
├─ 雷鎖術 chain_lightning（Lv.3）                               │
│   └─ 落雷術 lightning_strike（Lv.3）                          │
│       └─ 天雷降臨 heavens_thunder（Lv.5）                     │
│           └─ 神雷滅殺 divine_lightning_slaughter（Lv.8）──────┤
└─ 麻痺電擊 paralyzing_bolt（Lv.3）                              │
    └─ 雷獄囚縛 thunder_prison（Lv.3，分支終點）                 │
                                                                ▼
                                          雷霆神格 thunder_apotheosis
```

前置條件的 `Lv.N` 換算成實際施放次數請套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式：次數 = `50 × N ÷（種族學習倍率 × 屬性親和倍率）`，無條件進位。

## 節點設計說明

- **先制路線的雙分支**：雷神之速把「加速自己」的效果一路帶到審判雷霆，疾雷連擊·壞則是不追求位階提升、單純把連擊技巧磨到極致的分支終點，兩者代表「藉速度取勝」與「藉技巧取勝」的差異。
- **電擊術的雙分支**：雷鎖術／落雷術一路走向大範圍的神雷滅殺，麻痺電擊則專精控制，終點雷獄囚縛是全樹唯一以純控制（而非傷害）收尾的節點。
- **雷霆神格**：命中目標的行動順序被打到最後，是雷屬性「先制」哲學在神格位階的終極體現——不只是我先出手，而是讓你連下一次出手的機會都往後推。
