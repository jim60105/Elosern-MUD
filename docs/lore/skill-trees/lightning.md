# 雷屬性系譜樹

雷的獨佔動詞是**回合**：額外行動、行動順序操控、以及麻痺。麻痺在伊洛瑟恩的定義是「這輪你根本不存在」（行動順序被推後、擲骰輸則喪失當輪行動）。一句話切邊：**冰讓你動不了，雷是你這輪根本不存在**（見 [總覽](/lore/skill-trees/index) §4 配給制）。一條根走向先制與連續行動，一條根走向過載爆發與跳回合。

## 樹狀結構

```
【先制路線】
靜電護罩 static_ward（根）
└─ 雷光連閃 lightning_flicker（Lv.3）
    └─ 雷霆連擊 thunder_combo（Lv.3）── 分支點
        ├─ 雷神之速 thunder_gods_haste（Lv.5）
        │   └─ 審判雷霆 judgement_thunder（Lv.8）───────────────┐
        └─ 碎雷連擊 thunder_shatter_strike（Lv.5，分支終點）      │ 匯合
                                                                │
【過載路線】                                                    │
電擊術 spark_shock（根）── 分支點                               │
├─ 雷鎖術 chain_lightning（Lv.3）                               │
│   └─ 落雷術 lightning_strike（Lv.3）                          │
│       └─ 天雷降臨 heavens_thunder（Lv.5）                     │
│           └─ 神雷滅殺 divine_lightning_slaughter（Lv.8）──────┤
└─ 麻痺電擊 paralyzing_bolt（Lv.3）                              │
    └─ 雷獄囚縛 thunder_prison（Lv.3，分支終點）                 │
                                                                ▼
                                          雷霆神格 thunder_apotheosis
```

前置條件的 `Lv.N` 換算成實際施放次數請套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式，次數 = `50 × N ÷（種族學習倍率 × 屬性親和倍率）`，無條件進位。

## 節點設計說明

- **先制路線的雙分支**：雷神之速把「加速自己」的效果一路帶到審判雷霆，碎雷連擊則是不追求位階提升、單純把連擊技巧磨到極致的分支終點，兩者代表「藉速度取勝」與「藉技巧取勝」的差異。
- **電擊術的雙分支**：雷鎖術／落雷術一路走向大範圍的神雷滅殺，麻痺電擊則專精跳回合，終點雷獄囚縛是全樹唯一以純控制收尾的節點：它鎖的是對手下一次出手的機會。
- **雷霆神格**：命中目標的行動順序被打到最後，是雷屬性「先制」哲學在神格位階的終極體現，效果從自己先出手一路延伸到把對手下一次出手的機會也往後推。
