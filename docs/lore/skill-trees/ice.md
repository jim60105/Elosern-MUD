# 冰屬性系譜樹

冰的獨佔動詞是**物理性靜止**：從遲緩、束縛、凍結到定身的完整階梯，外加全遊戲唯一的「靜止標記」連動旗標，所有屬性打在冰標記上的增傷條文都引用本樹（見 [總覽](/lore/skill-trees/index) §4 配給制）。牆的本質是擋路。心理性靜止（恐懼）歸暗，冰讓身體動不了，暗讓意志動不了。

## 樹狀結構

```
【遲緩路線】
凍結之息 frost_breath（根）
└─ 冰牆術 ice_wall（Lv.3）── 分支點
    ├─ 凝霜泥沼 frost_mire（Lv.3，分支終點）
    └─ 永凍領域 permafrost_domain（Lv.3）                       ┐
        └─ 絕對凍土 absolute_tundra（Lv.8）                     │
            └─ 長夜冰原 eternal_ice_field（Lv.8）───────────────┤ 匯合
                                                                │
【監禁路線】                                                    │
冰錐術 ice_shard（根）                                          │
└─ 冷凍箭雨 frost_arrow_rain（Lv.3）                            │
    └─ 冰封監牢 ice_prison（Lv.3）── 分支點                     │
        ├─ 暴風雪 blizzard（Lv.5）                              │
        │   └─ 絕對零度 absolute_zero（Lv.8）───────────────────┤
        └─ 冰晶爆裂 crystal_shatter（Lv.5，分支終點）             │
                                                                ▼
                                        永凍神格 eternal_frost_apotheosis
```

前置條件的 `Lv.N` 換算成實際施放次數請套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式，次數 = `50 × N ÷（種族學習倍率 × 屬性親和倍率）`，無條件進位。

## 節點設計說明

- **冰牆術的雙分支**：凝霜泥沼把牆的範圍擴大成整片減速地面，永凍領域直接套用凍結 rung；兩條分支都沿靜止階梯排列，只是階梯跨度不同。
- **冰封監牢的雙分支**：暴風雪路線走向大範圍毀滅，冰晶爆裂則利用「目標已被冰封」這個前提放大傷害。連動旗標是冰對全隊伍的貢獻：凍結／定身標記是全遊戲增傷條文唯一引用的靜止旗標，冰法的團隊價值來自隊友對被標記目標的增傷條文。
- **永凍神格**：範圍毀滅疊加凍結控制，是「遲緩」與「監禁」兩種冰屬性哲學的最終合流，效果從遲緩一路升級到徹底停下來。
