# 冰屬性系譜樹

冰與雷互為表裡：雷讓己方更快，冰讓敵方更慢。系譜樹分成遲緩防禦與監禁爆發兩條根。

## 樹狀結構

```
【遲緩路線】
凍結之息 frost_breath（根）
└─ 冰牆術 ice_wall（Lv.3）── 分支點
    ├─ 寒霜壁壘 frost_bastion（Lv.3，分支終點）
    └─ 永凍領域 permafrost_domain（Lv.3）                       ┐
        └─ 絕對凍土 absolute_tundra（Lv.8）                     │
            └─ 永夜冰原 eternal_ice_field（Lv.8）───────────────┤ 匯合
                                                                │
【監禁路線】                                                    │
冰錐術 ice_shard（根）                                          │
└─ 冷凍箭雨 frost_arrow_rain（Lv.3）                            │
    └─ 冰封監牢 ice_prison（Lv.3）── 分支點                     │
        ├─ 暴風雪 blizzard（Lv.5）                              │
        │   └─ 絕對零度 absolute_zero（Lv.8）───────────────────┤
        └─ 冰晶爆裂 crystal_shatter（Lv.5，分支終點）             │
                                                                ▼
                                        永凍神格 eternal_frost_apotheosis
```

前置條件的 `Lv.N` 換算成實際施放次數請套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式：次數 = `50 × N ÷（種族學習倍率 × 屬性親和倍率）`，無條件進位。

## 節點設計說明

- **冰牆術的雙分支**：寒霜壁壘走純防禦，永凍領域走控制，呼應冰的「控制與攻擊並重」定位在術師位階就開始分家。
- **冰封監牢的雙分支**：暴風雪路線走向大範圍毀滅，冰晶爆裂則利用「目標已被冰封」這個前提放大傷害，是全樹唯一與另一個效果（凍結／定身狀態）產生連動的節點，鼓勵施法者搭配施放而非單獨使用。
- **永凍神格**：範圍毀滅疊加凍結控制，是「遲緩」與「監禁」兩種冰屬性哲學的最終合流——不只是讓你慢下來，而是讓你徹底停下來。
