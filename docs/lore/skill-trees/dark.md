# 暗屬性系譜樹

暗的獨佔動詞是**屬性增減益＋心理性靜止＋HP 掠取**：讓敵人先弱下去，削弱、侵蝕、恐懼伴隨每一階的傷害（見 [總覽](/lore/skill-trees/index) §4 配給制）。恐懼是心理性靜止，冰讓你動不了，暗讓你不想要動。HP 掠取是侵蝕 DoT 的延伸，凡掛上侵蝕的敵人流失的 HP 一律轉入施法者（憲法 §4.2 暗行邊界條款），這是暗與火的灼燒線在效果層的最後一道區辨。系譜樹分成詛咒（削弱）與吞噬（侵蝕）兩條根。

## 樹狀結構

```
【詛咒路線】
衰弱術 weaken（根）
└─ 詛咒術 curse（Lv.3）── 分支點
    ├─ 詛咒擴散 curse_spread（Lv.3）
    │   └─ 黑暗支配 dark_dominion（Lv.5，分支終點）
    └─ 暗影之刑 shadow_torture（Lv.3）                         ┐
        └─ 暗影侵蝕 shadow_blight（Lv.8）                      │
            └─ 冥界審判 underworld_judgment（Lv.8）───────────┤ 匯合
                                                                │
【吞噬路線】                                                    │
暗影箭 shadow_bolt（根）                                        │
└─ 闇裂術 dark_burst（Lv.3）                                    │
    └─ 闇蝕領域 dark_corrosion_domain（Lv.3）                   │
        └─ 深淵吞噬 abyss_devour（Lv.5）                        │
            └─ 虛空湮滅 void_annihilation（Lv.8）───────────────┤
                                                                ▼
                                              深淵神格 abyssal_apotheosis
```

前置條件的 `Lv.N` 換算成實際施放次數請套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式，次數 = `50 × N ÷（種族學習倍率 × 屬性親和倍率）`，無條件進位。

## 節點設計說明

- **詛咒術的雙分支**：詛咒擴散路線走向純減益（黑暗支配是全樹唯一沒有傷害、只靠恐懼控場收尾的分支，恐懼屬於暗的心理性靜止，與冰的物理性靜止在狀態層是兩個獨立鍵，玩家從敘述即可分辨來源），暗影之刑路線則把削弱與傷害結合成一條侵蝕愈演愈烈的處決線，兩種「讓敵人變弱」的手法在此分家。
- **侵蝕即掠取**：侵蝕是暗的 HP 掠取動詞的載具。凡受蝕者每次流失的 HP 全額轉入當初施加侵蝕的施法者。收益邊界由機制天然設防，敵人流完 HP 就無可再抽，對高 HP 的長耗損戰收益最大，對弱敵瞬間見底；施法者死亡或受蝕者死亡，該條掠取即熄滅。這條長尾讓暗術士在持久戰中越打越健康，是「讓敵人先弱下去」對應的回報面，也是暗與火的灼燒線在效果層唯一的區辨，火的灼燒只燒人，暗的侵蝕燒了還要回收。
- **掠取與自癒是兩回事**：虛空湮滅與深淵神格的「命中回復施法者已損 HP 的 10%／15%」是節點自身的戰地自癒條款，量基準在施法者自己身上，與侵蝕 tick 的掠取（量基準在敵人身上）互不相干、也互不重複計價。
- **吞噬路線**：從暗影箭到虛空湮滅是一條沒有分支的純粹遞增輸出線，每個節點都比前一個更狠，呼應「吞噬」哲學裡沒有回頭路的單向性。
- **深淵神格**：同時掛上大範圍減益、毀滅級傷害與自我回復三條性質不同的效果字串的節點，加上其侵蝕掠取，機制上示範一個節點可以疊加多種互不干擾的效果，敘事上代表暗屬性「削弱到底、吞噬到底」的哲學走到盡頭時反噬出的完整型態。
