# 暗屬性系譜樹

暗的核心是「讓敵人先弱下去」，系譜樹分成詛咒（削弱）與吞噬（侵蝕）兩條根。

## 樹狀結構

```
【詛咒路線】
衰弱術 weaken（根）
└─ 詛咒術 curse（Lv.3）── 分支點
    ├─ 詛咒擴散 curse_spread（Lv.3）
    │   └─ 黑暗支配 dark_dominion（Lv.5，分支終點）
    └─ 暗影凌遲 shadow_torment（Lv.3）                         ┐
        └─ 暗影侵蝕 shadow_blight（Lv.8）                      │
            └─ 冥府審判 netherworld_judgment（Lv.8）───────────┤ 匯合
                                                                │
【吞噬路線】                                                    │
暗影箭 shadow_bolt（根）                                        │
└─ 闇裂術 dark_burst（Lv.3）                                    │
    └─ 闇蝕領域 dark_corrosion_domain（Lv.3）                   │
        └─ 深淵吞噬 abyss_devour（Lv.5）                        │
            └─ 終焉黑洞 void_annihilation（Lv.8）───────────────┤
                                                                ▼
                                              深淵神格 abyssal_apotheosis
```

前置條件的 `Lv.N` 換算成實際施放次數請套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式：次數 = `50 × N ÷（種族學習倍率 × 屬性親和倍率）`，無條件進位。

## 節點設計說明

- **詛咒術的雙分支**：詛咒擴散路線走向純減益（黑暗支配是全樹唯一沒有傷害、只靠恐懼控場收尾的分支），暗影凌遲路線則把削弱與傷害結合成一條侵蝕愈演愈烈的處決線，兩種「讓敵人變弱」的手法在此分家。
- **吞噬路線**：從暗影箭到終焉黑洞是一條沒有分支的純粹遞增輸出線，每個節點都比前一個更狠，呼應「吞噬」哲學裡沒有回頭路的單向性。
- **深淵神格**：唯一同時具備大範圍減益、毀滅級傷害與自我回復三種效果的節點，機制上示範一個節點可以疊加三種不同性質的效果字串，敘事上代表暗屬性「削弱到底、吞噬到底」的哲學走到盡頭時反噬出的完整型態。
