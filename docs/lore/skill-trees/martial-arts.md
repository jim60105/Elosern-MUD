# 武藝系譜樹

武藝是體術與魔力結合的近戰流派，消耗的資源是**體力（SP）**而非魔力值，因此不套用魔法系譜的 MP 成本帶與威力係數表；位階稱號也換一套獨立的武術詞彙——**基礎／熟練／精通／奧義／宗師**——不與魔法的學徒到主宰混用，呼應世界觀「劍術與魔法是兩條不同的道路」。

系譜分成劍術與雙刀兩條根，各自收斂到自己的頂點；劍術頂點正是原始設定「大劍豪（S 級，全大陸不超過十人）」的機制定義。

## 樹狀結構

```
【劍術路線】                                                    ┐
基礎劍術 basic_swordplay（根）                                  │
└─ 流水連斬 flowing_strikes（Lv.3）── 分支點                    │
    ├─ 破甲斬 armor_breaker（Lv.3）                             │
    │   └─ 千刃絕技 thousand_blade_art（Lv.5）                  │
    │       └─ 劍聖絕藝 blade_saint_arts（Lv.8）─────────────────┤ 匯合
    └─ 迴旋斬 whirlwind_slash（Lv.3）                            │
        └─ 劍刃風暴 blade_storm（Lv.5）                          │
            └─ 千軍斬 thousand_army_slash（Lv.8）─────────────────┤
                                                                ▼
                                                真·劍聖 true_sword_saint

【雙刀路線】（需另外持有被動架式「雙持劍術」dual_wield_style，見下方說明）
影斬 shadow_slash（根）
└─ 幻影連斬 phantom_dance（Lv.3）── 分支點
    ├─ 雙刀流·宗師級 dual_blade_mastery（Lv.5）───────────────┐
    └─ 暗影絕殺 shadow_veil_execution（Lv.5）                  │ 匯合
                                                              ▼
                                        暗影劍舞·絕 shadow_dance_transcendence
```

## 節點設計說明

- **位階詞彙獨立於魔法**：武藝用「基礎／熟練／精通／奧義／宗師」，刻意不借用「學徒／術師／大師／賢者／主宰」，因為兩者是完全不同的力量來源（體術鍛鍊 vs 魔力運用），世界觀也明確區分兩套敬語體系。
- **雙刀路線需要一個額外門檻**：`dual_wield_style`（雙持劍術）是 PASSIVE 架式，不計入前置系譜（PASSIVE 沒有使用熟練度），但敘事與規則上都應該要求角色先持有這個架式，才談得上鑽研影斬以後的雙刀技法——這是系譜前置機制之外、額外疊加的「裝備／架式門檻」，設計上與 `SkillPrerequisite` 分開處理。
- **`dual_blade_mastery` 的命名早於本系譜設計**：它原本的中文名稱就叫「宗師級」，但本次設計在它之上又放了 `shadow_dance_transcendence`。這不是矛盾，而是刻意保留：舊有的「宗師級」在雙刀流傳統裡確實是頂點，`shadow_dance_transcendence` 則是融合劍術路線技巧後才可能達到的、超越傳統雙刀流框架的境界，全大陸目前沒有已知角色達到。
- **真·劍聖**：唯一同時精通單體處決與範圍毀滅兩種劍技的存在，機制上直接對應原始設定「大劍豪（S 級）全大陸不超過十人」——換句話說，`true_sword_saint` 的持有者就是設定文字裡那不到十人的其中之一。
