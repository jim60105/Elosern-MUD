# 神之秘法系譜樹

神之秘法的學習條件是「具備神性」，只有精靈族的三個分支符合，人類與獸人無論多麼努力都無法觸及，也就不存在「人類版本」的換算或例外。與元素魔法不同，神之秘法消耗的是**精神力**而非魔力值，而精神力目前**未在遊戲中數值化**，僅作為敘事風味存在。對已領悟的秘法，精靈的使用是「隨心所欲」的，無資源成本、無每日次數限制、無位階階層把關。

## 0. 開放類別：三種存在形態

神之秘法是一個**沒有已知上限的開放類別**，不是四項的固定清單。世界觀中的秘法分三種存在形態，只有第一種有系譜樹：

| 形態 | 說明 | 系譜 | 範例 |
| --- | --- | --- | --- |
| 傳承體系 | 已編入精靈長老口傳目錄、可被任何具神性精靈學習的共通招式體系 | 有：每條體系是一條獨立淺鏈，四鏈匯合出終極節點 | 時間、空間、物質、生命四條鏈 |
| 單節點既知秘法 | 同樣在共通認知內、但結構上只有一招的秘法；神之秘法不一定要成「樹」，單一節點是完全合理的形態 | 無：取得即可用，沒有深化階梯 | 狀態偽裝、統御術 |
| 自創體系 | 個別精靈自行開發、只屬於開發者（或其明確傳授的對象）的獨創體系；類別擴充的主要來源，未來隨劇情與規則需要持續新增 | 無：不入任何系譜樹，由取得事件直接授予 | 悠奈・玄夜的「神之秘法：性愛系統」 |

自創體系在**機制分類**上未必掛在 `DIVINE_MYSTERY` 之下。例如性愛系統及其神性七招在技能目錄中歸情慾秘術分支、由獨立計數器與血統閘門把關，這屬於實作分桶，不改變它們在世界觀上「是神之秘法」的事實。同樣地，狀態偽裝與統御術是貨真價實的神之秘法（單節點形態），機制分類也已歸回 `DIVINE_MYSTERY`。

## 0.1 使用、學習、深化：三件事三個把關者

「隨心所欲使用」與「遊戲成長平衡」不衝突，因為它們管的是不同的事。刷等漏洞的根源是把**解鎖**掛在使用計數器上、而使用又是零成本，因此修正方式是直接把三軸拆開，保持使用本身零成本、無階層（給使用加階層或成本反而違背設定）：

| 軸 | 回答的問題 | 把關者 |
| --- | --- | --- |
| 使用 | 這一刻能不能出手 | 持有該技能 + 神性血統閘門。**無成本、無階層、無冷卻**；精靈對已領悟的秘法就是隨心所欲 |
| 學習 | 新節點怎麼來 | **鑽研制**：系譜邊是研究途徑。相鄰節點的取得（ownership）由自主鑽研的時間推進授予（呼應精靈「自學／口傳、無學校」的設定），亦可由劇情授予捷徑；受系統限制的是「鑽研進度」，不是「使用」 |
| 深化 | 既有節點變強 | 使用熟練度照舊，但神之秘法有**消化節拍**：每個秘法**每日（每個日曆日）只有第一次「有意義使用」累計熟練度**；對真實、會被影響或改變狀態的目標生效才算數，對空處連發一律不計 |

消化節拍（每日 1 次、極慢、劇情導向）是設計拍板的節奏參數，**尚未在 `world/rules/progression.py` 實作**，屬本系譜落地時要一併撰寫的規則工作；現行引擎的「同一時鐘刻只計一次」去重與研習時數機制是它的實作起點。學習與深化的意義因此得以保留，成長曲線由鑽研速率與消化節拍共同決定，零成本使用只還原精靈的權力幻想，不再決定任何人解鎖了什麼。

## 1. 傳承體系：四條既知鏈

四條既知秘法（時間、空間、物質、生命）各自是一條獨立、不分支的四節點淺鏈，彼此平時互不相干；要匯合出神之秘法真正的頂點，必須把四條鏈全部磨練到系譜上限。

### 樹狀結構

```
時間感知 chrono_attunement（根）              空間感知 spatial_sense（根）
└─ 時間遲滯場 temporal_lag_field（Lv.3）      └─ 短距瞬移 short_blink（Lv.3）
    └─ 群體加速陣 mass_haste_field（Lv.3）        └─ 眾人摺躍 party_fold（Lv.3）
        └─ 因果回溯 causal_rewind（Lv.5）──┐          └─ 空間鎖定 dimensional_lock（Lv.5）──┐
                                          │                                              │
物質洞察 material_insight（根）             │ 匯合                                          │ 匯合
└─ 小型轉換 minor_transmute（Lv.3）         │                                              │
    └─ 煉金合成 alchemical_synthesis（Lv.3）│                                              │
        └─ 巨物轉換 grand_transmutation（Lv.5）─┤                                          │
                                              │                                          │
生命感知 vital_sense（根）                     │                                          │
└─ 延命庇護 minor_life_ward（Lv.3）            │                                          │
    └─ 抗齡結界 age_ward（Lv.3）               │                                          │
        └─ 死門庇護 deaths_door_ward（Lv.5）───┴──────────────────────────────────────────┘
                                                                                          ▼
                                                                    神格 true_apotheosis
```

前置條件的 `Lv.N` 換算成實際「有意義使用」次數，套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的同一公式，次數 = `50 × N ÷ 精靈學習倍率（10.0）`，神之秘法沒有屬性親和加成，只有這一種倍率，因為只有精靈用得上這條公式。以此計算，Lv.3 為 15 次、Lv.5 為 25 次、Lv.10（樹冠上限）為 50 次。搭配每日 1 次的消化節拍，換算成遊戲節奏就是**累計約 N 個遊戲日的有意義實戰**，Lv.3 節點要 15 個遊戲日、Lv.5 要 25 日、見頂要 50 日，慢到神之秘法的深層幾乎必然與一段劇情同行，快不到讓鑽研變成掛機。

## 2. 單節點既知秘法

以下兩項是神之秘法的單節點形態，世界觀上具神性者皆可鑽研取得，結構上只有一招、沒有「越練越強」的深化階梯，取得即可用、使用零成本：

| Key | 名稱 | 效果 | 系譜 |
| --- | --- | --- | --- |
| `status_disguise` | 神之秘法：狀態偽裝 | 偽裝自身外貌與部分能力數值 | 無，單一節點，要求神性才能取得 |
| `dominion_art` | 統御術 | 授予目標一部分自身技能的效果 | 無，單一節點，要求神性才能取得 |

它們的機制分類已歸回 `SkillCategory.DIVINE_MYSTERY`，與 [雜學秘術系譜樹](/lore/skill-trees/utility) 中三種族皆可學的鑑定／儲物系譜畫出分界，後者屬於技術。兩者都宣告 `requires_divine_arts=True`，「只有神性能用」從資料面慣例升級為施放當下的機械血統閘門（`world/rules/action.py` 的 `_step1_divine_arts_gate` 復用 `RaceProfile.can_use_divine_arts`），與四項傳承秘法共用同一道閘門。

## 3. 自創體系（範例）

自創體系不入本文件任何系譜樹；下表僅記錄目前已知案例在**機制上**掛在哪個分類、由什麼把關，作為世界觀形態與實作分桶的對照：

| 自創體系 | 開發者 | 機制分類與把關 |
| --- | --- | --- |
| 神之秘法：性愛系統（含神性七招） | 悠奈・玄夜 | 情慾秘術分類；`requires_divine_arts` 血統閘門 + `ownership_gated` 只認實際持有，計數器與主宰全解都繞過它（見 [情慾秘術](/lore/skill-trees/sexual-act)） |
| 性魔法主宰 | （未知） | 情慾秘術分類的頂點被動；全面解鎖前五條線，不涵蓋神之秘法線 |

新增自創體系是劇本層的自由擴充點，一個新秘法就是新的取得事件（劇情授予或自主鑽研），不需要動任何系譜樹。
