# 神之秘法系譜樹

神之秘法的學習條件是「具備神性」——只有精靈族的三個分支符合，人類與獸人無論多麼努力都無法觸及，也就不存在「人類版本」的換算或例外。與元素魔法不同，神之秘法消耗的是**精神力**而非魔力值，且結構刻意比元素魔法淺：這不是偷懶，而是敘事上的必然——全大陸具備神性的個體不到三百人，願意認真鑽研到深層節點的更是稀少，系譜樹沒有必要長得跟元素魔法一樣枝繁葉茂。

四項既知秘法（時間、空間、物質、生命）各自是一條獨立、不分支的四節點淺鏈，彼此平時互不相干；只有把四條鏈全部磨練到系譜上限，才能匯合出神之秘法真正的頂點。

## 樹狀結構

```
時間感知 chrono_attunement（根）              空間感知 spatial_sense（根）
└─ 時間遲滯場 temporal_lag_field（Lv.3）      └─ 短距瞬移 short_blink（Lv.3）
    └─ 群體加速陣 mass_haste_field（Lv.3）        └─ 眾人摺躍 party_fold（Lv.3）
        └─ 因果回溯 causal_rewind（Lv.5）──┐          └─ 空間鎖定 dimensional_lock（Lv.5）──┐
                                          │                                              │
物質洞察 material_insight（根）             │ 匯合                                          │ 匯合
└─ 小型轉換 minor_transmute（Lv.3）         │                                              │
    └─ 煉金合成 alchemical_synthesis（Lv.3）│                                              │
        └─ 巨物轉換 grand_transmutation（Lv.5）─┤                                          │
                                              │                                          │
生命感知 vital_sense（根）                     │                                          │
└─ 延命庇護 minor_life_ward（Lv.3）            │                                          │
    └─ 抗齡結界 age_ward（Lv.3）               │                                          │
        └─ 死門庇護 deaths_door_ward（Lv.5）───┴──────────────────────────────────────────┘
                                                                                          ▼
                                                                    真·神格 true_apotheosis
```

前置條件的 `Lv.N` 換算成實際施放次數，套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式：次數 = `50 × N ÷ 精靈學習倍率（10.0）`——神之秘法沒有屬性親和加成，只有這一種倍率，因為只有精靈用得上這條公式。以此計算，Lv.3 為 15 次、Lv.5 為 25 次、Lv.10（樹冠上限）為 50 次。

## 神之秘法之外、同樣要求神性的技能

以下兩個技能名稱掛著「神之秘法」，實際的機制分類卻是雜學秘術（見 [魔法技能體系](/lore/magic-system) 第 9 節），且目前設計為單一節點、不建立系譜前置——效果偏向資訊操作與能力分享，不是可以「越練越強」的力量：

| 技能 | 效果 | 是否有系譜 |
| --- | --- | --- |
| 狀態偽裝 | 偽裝自身外貌與部分能力數值 | 無，單一節點，取得即可用 |
| 統御術 | 授予目標一部分自身技能的效果 | 無，單一節點，取得即可用 |

情慾秘術分支（見 [魔法技能體系](/lore/magic-system) 第 10 節）中要求神性的「性魔法主宰」與「神之秘法：性愛系統」也不掛在本系譜樹下，其解鎖階梯由獨立的情慾秘術計數器把關，本文件不展開細節。
