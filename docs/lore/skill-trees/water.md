# 水屬性系譜樹

水同時肩負治療與深海攻控兩種性格，系譜樹在學徒位階就分成兩條互不相交的根：一條走向治癒與守護，一條走向深海的吞噬與束縛。

## 樹狀結構

```
【治癒路線】
治癒滴露 minor_heal（根）
└─ 水盾術 water_shield（Lv.3）
    └─ 治癒之泉 healing_spring（Lv.3）── 分支點
        ├─ 生命湧泉 wellspring_of_life（Lv.5）
        │   └─ 復生之潮 tidal_revival（Lv.8）
        │       └─ 生命之海 sea_of_life（Lv.8）──┐
        └─ 潮汐聖域 tidal_sanctuary（Lv.5，分支終點）          │ 匯合
                                                                │
【深海路線】                                                    │
水箭術 water_bolt（根）                                         │
└─ 深流刺 deep_current_spike（Lv.3）                            │
    └─ 深海漩渦 abyssal_whirlpool（Lv.3）── 分支點              │
        ├─ 海嘯術 tsunami（Lv.5）                               │
        │   └─ 深淵巨潮 abyssal_tide（Lv.8）───────────────────┤
        └─ 深淵巨口 abyssal_maw（Lv.5，分支終點）                │
                                                                ▼
                                            滄海神格 abyssal_heart
```

前置條件的 `Lv.N` 換算成實際施放次數請套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式：次數 = `50 × N ÷（種族學習倍率 × 屬性親和倍率）`，無條件進位。

## 節點設計說明

- **潮汐聖域**：治癒路線在大師位階的第二分支，示範「同一節點養出兩種不同定位的下一階段技能」——生命湧泉走向單體急救，潮汐聖域則走向範圍持續治療，兩者互不衝突，可各自練到見頂。
- **深流刺**：補上深海路線在術師位階的攻擊節點，銜接學徒的水箭術與大師的深海漩渦，避免攻擊分支在術師位階出現斷層。
- **深淵巨口**：深海漩渦的第二個大師後續節點，賦予深海路線一個以資源回收（回復 MP）為賣點的分支終點，與海嘯術的純輸出形成對比。
- **滄海神格**：唯一同時具備「一擊毀滅」與「全體重生」兩種效果的節點，敘事上代表水屬性「生與死同源」的核心哲學——深淵與生命之海本是同一片海洋的兩種面貌。
