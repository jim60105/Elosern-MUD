# 水屬性系譜樹

水的獨佔動詞是**魔力潮汐**：搬動對手的 MP，也搬動自己人的 MP。水是反法術之戰的屬性，讓智慧敵人的魔力流走、讓己方的魔力回流。**取與予**是水的語言，同一個動作可以抽乾一片戰場，也可以灌滿一隊同伴。

系譜樹在學徒位階分成兩條根，一條走向潮汐（掠奪與歸還），一條走向深海（傷害與壓制）。

## 樹狀結構

```
【潮汐路線】
潮引術 tide_pull（根）
└─ 潮退侵蝕 ebbing_blight（Lv.3）
    ├─ 水膜護身 water_shield（Lv.3）
    └─ 回流之環 ring_of_reflux（Lv.3）── 分支點
        ├─ 溺潮 drowned_surging（Lv.5）
        │   └─ 枯海之印 sigil_of_the_barren_sea（Lv.8）──┐
        └─ 深淵潮汛 abyssal_surge（Lv.5）─────────────┤ 匯合
                                                          │
【深海路線】                                              │
水箭術 water_bolt（根）                                   │
└─ 深流刺 deep_current_spike（Lv.3）                      │
    └─ 深海漩渦 abyssal_whirlpool（Lv.3）── 分支點        │
        ├─ 海嘯術 tsunami（Lv.5）                          │
        │   └─ 深淵巨潮 abyssal_tide（Lv.8）───────────────┤
        └─ 深淵巨口 abyssal_maw（Lv.5，分支終點）          │
                                                          ▼
                                            深海神格 abyssal_heart
```

前置條件的 `Lv.N` 換算成實際施放次數請套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式，次數 = `50 × N ÷（種族學習倍率 × 屬性親和倍率）`，無條件進位。

## 節點設計說明

- **潮引術**：全遊戲第一個讓「對手的資源條」成為目標的根節點。−5 回收一半的數字不重要，重要的是玩家第一次意識到：法術敵人最怕的一刻是被抽。
- **潮退侵蝕／溺潮的階梯**：潮退是可疊加的 MP 流失標記（語法同灼燒／侵蝕 DoT，目標槽換成 MP）；溺潮把流失速率推到歸零，魔力歸零的目標陷入窒息。對魔力上限為零的野獸型敵人，溺潮自動改道為等值傷害，本樹對無魔力目標不失值。
- **水膜護身**：受擊時護膜以 MP 代扣打擊量。這是全遊戲唯一以魔力承擔打擊的護盾，保護的資源與掠奪的資源是同條 MP 條。
- **回流之環／深淵潮汛**：MP 歸還分成兩個面向，單體急救讀「潮退」標記層數（你抽了多少，就能還多少），友方範圍的「回流」層讓全隊共享潮引系節點的回收量，形成團隊的魔力循環。歸還量沿用道具層 `mana_restore` 的既有量級，不新造增量。
- **枯海之印**：枯海之印的處決對象是目標的 MP 來源：移除全部 MP 並封鎖恢復 60 秒。公會新人「遇水系就跑」民謠的機制出處。
- **深海漩渦的束縛**：漩渦附帶的束縛是單句修飾，不成控制支線。
- **深淵巨口**：吸取按目標現有 MP 比例計算，目標魔力越深，回收越多，呼應「深海無底」的意象。
- **深海神格**：敘事是「**取予同源**」：同一個動作抽乾敵方全體的 MP、灌滿我方全體的 MP。

## 與相鄰系統的接縫

- **MP 池與血統區間**：掠奪收益的上限由目標的血統 MP 池決定：人類 MP 池 100–200，一發溺潮就能抽空；精靈固定 10000 的池子讓枯海之印的「移除全部 MP」對精靈幾乎無感，這是水系法師對陣精靈時的天然劣勢，與「精靈是皇族之上」的世界觀位置互相印證（見 [魔法技能體系](/lore/magic-system) 第 11 節）。
- **假貨市場**：水屬性從來不治傷，市面上販賣的「治癒泉水」是 [假貨市場](/lore/magic-system) 的經典騙局，鑑定系譜的標準靶。
- **光屬性**：治療漏斗收斂到光之後，隊伍要回血就必須帶著聖職者（見 [光屬性系譜樹](/lore/skill-trees/light)）；水系與光系因此互補：水管魔力循環，光管生命循環。
