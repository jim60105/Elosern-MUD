# 火屬性系譜樹

火的獨佔動詞是**HP・消滅**：爆發、處決、灼燒 DoT，以及以自身為柴的代價換爆發（見 [總覽](/lore/skill-trees/index) §4 配給制）。系譜樹的核心矛盾因此是「往外爆發」與「燃身換爆發」兩條路線的取捨。

## 樹狀結構

```
火焰箭 fire_arrow（根）
└─ 火球術 fire_ball（Lv.3）
    └─ 灼熱波動 scorching_wave（Lv.3）── 三分支點
        ├─ 火焰風暴 firestorm（Lv.3）
        │   ├─ 熔岩術 lava_burst（Lv.5）
        │   │   └─ 龍炎術 dragon_flame（Lv.8）
        │   │       └─ 燔祭焰 sacrificial_flame（Lv.8）─────────────┐
        │   └─ 煉獄之火 hellfire（Lv.5）                          │ 匯合
        │       └─ 焚世之焰 final_blaze（Lv.5）──────────┤
        ├─ 烈焰纏繞 flame_shroud（Lv.3，分支終點）              │
        └─ 灼熱裝甲 scorching_armor（Lv.3，分支終點）             │
                                                                  ▼
                                              紅蓮神格 crimson_apotheosis
```

前置條件的 `Lv.N` 換算成實際施放次數請套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式，次數 = `50 × N ÷（種族學習倍率 × 屬性親和倍率）`，無條件進位。

## 節點設計說明

- **灼熱裝甲**：讓灼熱波動的分支從「雙叉」變成「三叉」的支線終點。火的「護甲」是讓攻擊者燒傷。
- **燔祭與紅蓮的燃身條款**：燔祭是現存記載中最古老的獻祭儀式，獻上最有價值之物，而燔祭焰獻上的是施法者自身的體能。燔祭焰 3.4、紅蓮神格 4.4 兩個刻意超出位階級距的係數，都以其自身的灼燒 DoT 為代價。這是火獨有的機制「**燃身換爆發**」：自傷換來當擊威力係數上浮，燃燒自身即為獻給那一擊的祭品。紅蓮神格需要把「燃身（燔祭）路線」與「焚滅（焚世之焰）路線」都磨到系譜上限才會匯合，機制上示範系譜樹的匯合（AND 前置）語意，敘事上代表施法者短暫觸及了光明女神留下的神性殘留，全大陸目前沒有已知角色達到這個境界。

`fire_mastery`（火焰精通）屬於 PASSIVE 精通被動，不屬於系譜節點。擁有它會整體強化本樹所有節點的威力係數表現，取得方式是劇情授予或匯入，而非使用累計。
