# 火屬性系譜樹

火是攻擊性最強的屬性，系譜樹的核心矛盾是「往外爆發」與「向內自癒」兩條路線的取捨。

## 樹狀結構

```
火焰箭 fire_arrow（根）
└─ 火球術 fire_ball（Lv.3）
    └─ 灼熱波動 scorching_wave（Lv.3）── 三分支點
        ├─ 火焰風暴 firestorm（Lv.3）
        │   ├─ 熔岩術 lava_burst（Lv.5）
        │   │   └─ 龍炎術 dragon_flame（Lv.8）
        │   │       └─ 不滅鳳凰焰 phoenix_eternal_flame（Lv.8）──┐
        │   └─ 煉獄業火 hellfire（Lv.5）                          │ 匯合
        │       └─ 焚世終焰 world_ending_blaze（Lv.5）──────────┤
        ├─ 業火纏繞 infernal_wrap（Lv.3，分支終點）              │
        └─ 灼熱裝甲 scorching_armor（Lv.3，分支終點）             │
                                                                  ▼
                                              紅蓮神格 crimson_apotheosis
```

前置條件的 `Lv.N` 換算成實際施放次數請套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式：次數 = `50 × N ÷（種族學習倍率 × 屬性親和倍率）`，無條件進位。

## 節點設計說明

- **灼熱裝甲**：讓灼熱波動的分支從「雙叉」變成「三叉」，補上一條不往上爬位階、單純以自我防禦為目的的支線，示範同一個節點可以同時養出攻擊、範圍與自我強化三種不同性質的下一階段技能。
- **紅蓮神格**：唯有同時把「永恆（鳳凰）路線」與「焚滅（終焰）路線」都磨練到系譜上限，才能匯合出的終極型態，機制上示範系譜樹的匯合（AND 前置）語意——不是分支的相反，而是分支之後重新交會。敘事上代表施法者短暫觸及了光明女神留下的神性殘留，全大陸目前沒有已知角色達到這個境界。

`fire_mastery`（火焰精通）作為 PASSIVE 精通被動，不是系譜節點：擁有它會整體強化本樹所有節點的威力係數表現，取得方式是劇情授予或匯入，而非使用累計。
