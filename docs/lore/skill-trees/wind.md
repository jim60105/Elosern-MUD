# 風屬性系譜樹

風的獨佔動詞是**動作與閃避**：己方加速、命中與迴避的兩極、擊退、多段（見 [總覽](/lore/skill-trees/index) §4 配給制）。敵方減速不歸風——那是冰靜止階梯的第一 rung；風只讓自己更快、更難打中。一條根扎向機動，一條扎向破壞。飛行術雖然由風元素的魔力驅動，但機制上獨立於本樹之外，歸類在「身法」分支（見 [魔法技能體系](/lore/magic-system) 第 7 節）。

## 樹狀結構

```
【機動路線】
疾風術 gale_step（根）
└─ 疾風連步 gale_chain_step（Lv.3）
    └─ 神速殘影 afterimage_step（Lv.3）
        └─ 神速領域 haste_domain（Lv.5，分支終點）

【破壞路線】                                                        ┐
風刃術 wind_blade（根）                                             │
└─ 龍捲風刃 tornado_blade（Lv.3）── 分支點                          │
    ├─ 暴風領域 storm_domain（Lv.3）                                │
    │   └─ 天譴風暴 heavens_wrath_storm（Lv.5）                     │
    │       └─ 蒼穹暴風 sky_tempest（Lv.8）───────────────────────┤ 匯合
    └─ 疾風刃舞 gale_dance_strike（Lv.3）                            │
        └─ 天穹裂斬 sky_rending_slash（Lv.8）                        │
            └─ 真空斬滅 vacuum_severance（Lv.8）───────────────────┤
                                                                    ▼
                                                天穹神格 sky_apotheosis
```

前置條件的 `Lv.N` 換算成實際施放次數請套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式，次數 = `50 × N ÷（種族學習倍率 × 屬性親和倍率）`，無條件進位。

## 節點設計說明

- **機動路線**（疾風術→疾風連步→神速殘影→神速領域）全程沒有一個節點造成傷害，是八屬性中唯一一條純粹以「先讓自己更快」為目的的完整支線，終點神速領域是全隊性的加速結界，而非個人爆發技。路線上的命中減益（神速殘影）與迴避全部站在命中的風之極上；風不減敵速、不改回合——快是風的，慢是冰的，回合是雷的。
- **龍捲風刃的雙分支**：疾風刃舞分支追求單體多段爆發，暴風領域分支追求範圍持續壓制，兩條路線平行發展到各自的主宰節點才交會。
- **天穹神格**：匯合「範圍毀滅」與「單體處決」兩種完全不同的傷害形狀，敘事上代表施法者同時掌握了風的兩種面貌，包覆一切的暴風與斬開一切的真空。
