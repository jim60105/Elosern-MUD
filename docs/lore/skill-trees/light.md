# 光屬性系譜樹

光是唯一在最高位階仍保留純輔助定位的屬性，系譜樹分成治療與聖裁兩條根，是光明教會信仰體系在魔法上最直接的體現。

## 樹狀結構

```
【治療路線】
治癒術 heal（根）
└─ 群體治癒 mass_heal（Lv.3）── 三分支點
    ├─ 高級治癒 advanced_heal（Lv.3）
    │   └─ 復甦之光 revival_light（Lv.5）
    │       └─ 女神降福 goddess_blessing（Lv.8）──────────────┐
    ├─ 聖盾術 holy_shield（Lv.3，分支終點）                     │ 匯合
    └─ 聖光庇護陣 sanctified_ward（Lv.3，分支終點）              │
                                                                │
【聖裁路線】                                                    │
光箭術 light_arrow（根）                                        │
└─ 淨化術 purify（Lv.3）                                        │
    └─ 聖裁斬 judgment_strike（Lv.3）                           │
        └─ 神聖光輝 holy_radiance（Lv.5）                       │
            └─ 天啟聖裁 heavens_judgment_light（Lv.8）──────────┤
                                                                ▼
                                              光輝神格 radiant_apotheosis
```

前置條件的 `Lv.N` 換算成實際施放次數請套 [總覽與機械規則](/lore/skill-trees/index) §1.1 的公式：次數 = `50 × N ÷（種族學習倍率 × 屬性親和倍率）`，無條件進位。

## 節點設計說明

- **群體治癒的三分支**：高級治癒延續純治療路線，聖盾術與聖光庇護陣分別代表「單體防禦」與「範圍持續防禦＋回復」兩種守護型態，是光屬性在大師位階最豐富的分支點。
- **聖裁斬**：補上聖裁路線在大師位階缺少的節點，銜接術師的淨化術與賢者的神聖光輝，讓「淨化」與「討伐」自然銜接成同一條支線。
- **光輝神格**：唯一同時對敵我雙方施展不同效果（我方治療、敵方毀滅）的節點，機制上示範一個效果字串也可以同時服務兩種陣營，敘事上正是光明女神教義「恩賜與審判同源」的體現。
