# 光屬性系譜樹

光的裡設定只有一條：**快感與生命力在伊洛瑟恩是同股魔力**。性之歡愉是生命力最旺盛的狀態，所以光能治療；高潮是身體毫無殘留的坦誠瞬間，所以光能淨化；而興奮越接近光明女神，施法者的回復力越強。教會聖典把這一切寫成教義，本系譜樹把教義寫成機制。

全篇使用情慾系統的既有實作術語（`world/rules/sexual_state.py`、`world/rules/rulebook/sexual.yaml`）：

- **興奮**＝pleasure 計（0–100）經帶狀表推導的五階等級：平靜／微興奮／中等／高度／極限。
- **高潮期相**＝循環序：未達 →（pleasure 到極限）接近 →（再受一次刺激）進行中 →（settled）餘韻 → 回到未達。
- **露出**（exposure）＝獨立等級軸，有效值＝固有值＋裝備 `exposure_bias` 疊加後封頂（`effective_exposure`）。

這條裡設定同時解釋光的雙重身分：

- **對任何魔法使**：光是一門體面、正經的元素魔法——治療、淨化、對不死系的聖裁，低階節點完全不含性意涵，帝國魔法學院的課堂上就這樣教。
- **對聖職者**：光是被充分驅動的情慾系統的放大器。聖職者的戰鬥哲學是**捨棄防禦**——露出度越高、防禦越低（`high_exposure_defense_penalty`，已實裝），但露出、刺激與性行為把興奮一路推高，而興奮讓她們更接近女神。這個方向已有機制雛形：教會聖袍的恩寵規則（興奮 ≥ 中等時防禦 +4／+6、光輝聖徽在興奮 ≥ 高度時 `heal_gain` +10%，均已實裝於 `combat_modifiers.yaml`）。聖職者因此以「受傷換快感、快感換回復」的循環作戰，痛苦本身也被被動轉化為快感（設計目標，見聖職者系統表）。同一套光魔法，聖職者用得比任何同位階魔法使都強，強在她們願意讓光真正進入身體。

因此系譜樹的形狀本身就是階級：**恩寵路線前半段是任何人都能修練的一般光魔法，〔聖禮〕節點則把施法條件綁在情慾狀態上**——非聖職者可以擁有這些節點，但不願或不能充分使用情慾系統的施法者，永遠只摸到光的天花板下緣。聖裁路線維持一般光魔法的討伐定位（教會對不死與暗屬性的敵意本來就不需要寬衣解帶）。

## 節點設計說明

- **前半段的「正經」光魔法**：`heal`、`mass_heal`、`advanced_heal`、`revival_light` 與整條聖裁路線完全不含性意涵，任何魔法使都能當常規元素魔法使用。這保證非聖職者有一條走得完的光屬性路線（到女神降福為止），也保證教會以外的人對光魔法的日常印象就是「治療與淨化」——裡設定的衝擊力正來自於深層節點跟這份體面印象的反差。
- **聖光庇護陣**：「捨棄防禦」哲學的第一個機制化節點。它給的不是防禦而是 HOT，且回復量由受護者的**有效露出**計價——把已實裝的「露出越高、防禦越低」減益直接翻面成光屬性的收益面。修女團的標準陣型就是全員站在這圈裡寬衣解帶地挨打。
- **女神降福 vs 聖吻之癒**：復甦之光之後的分支點把兩類施法者正式分岔。女神降福是一般光魔法的名義巔峰（主宰係數＋防禦增益），誰都能練完；聖吻之癒是同一位階的**上限相同但需興奮狀態啟動**的版本（滿階才回到 4.0，未滿階一律打折），並透過前置鏈把後續拉進聖禮路線。兩者是刻意留下的岔路，而非門檻歧視——不碰情慾系統的魔法使在這裡練女神降福見頂，正是設計意圖。
- **聖吻之癒 → 女神之乳 → 天賜高潮**：聖禮三節點依次把「興奮提升回復力」「體液交換＝最純的生命力輸送」「高潮＝極大範圍回復」三條裡設定逐一機制化。前兩節點的施放條件讀既有狀態：興奮等級（pleasure 帶狀表）、有效露出（存儲值＋裝備 bias），本樹不另立欄位；pleasure 推進量沿用 `stimulus_applied` 的既有幅度帶，不新造增量。
- **天賜高潮與行動鎖定的取捨**：實裝中進行中（高潮中）鎖定全部行動（`actions_per_turn: 0`），且前幾個結算點對抵抗有自動順從短路——高潮在系統裡本來就是**最脆弱**的狀態。天賜高潮不設興奮門檻、改為施放時強制推滿 pleasure，讓它成為聖職者的**應急底牌**：無論先前戰鬥中攢到多少快感，這一術都能把自己直接推過臨界換全隊回滿——但施放即自陷行動鎖定，隊伍必須在餘韻結束前保護她。這是把「奶媽需要被保護」反轉成「奶媽需要被打、被用、然後被保護」的完整閉環，而不是繞開鎖定規則；強制推進複用的正是 `divine_pleasure_max`（神之秘法頂點技）已驗證的雙邊前進路徑，落地風險最低。
- **歡喜神格**：由**天賜高潮＋天啟聖裁**兩條主宰路線匯合——光是八屬性裡唯一「神格節點要求走完整條聖禮路線」的屬性，敘事上等於宣告：只練一般光魔法的施法者觸不到光的神格，歡喜神格從未被任何人達成過，因為它從一開始就不是靠「練」能到的。機制上〔聖禮〕節點的滿值條件綁定高潮期相這個跨系統狀態，而不只是熟練度。

## 聖職者系統（本樹的驅動面，非系譜節點）

以下機制掛在光屬性與情慾系統的連動上，按 index §1 的紀律，被動不進系譜樹。「實裝狀態」為本設計文件的落地盤點：

| 項目 | 機制定位 | 實裝狀態與內容 |
| --- | --- | --- |
| 痛苦轉換（`pain_to_pleasure`） | PASSIVE，劇情／聖職敘階授予，無法靠使用練習取得 | **尚未實作（本設計新增）**：承受傷害與負面狀態時，將痛苦按位階級距轉換為 pleasure 推進。這是「受傷換快感、快感換回復」戰鬥循環的第一個齒輪；落地時歸屬 `world/skills/` 被動效果，複用 `_apply_pleasure_gain` 路徑，讓濕潤、興奮帶與高潮期相邊緣自動跟隨（該函式已是現成 chokepoint） |

| 露出計價 | 露出度↑ → 防禦↓ 在光屬性的收益面翻轉 | **減益側已實裝**（`high_exposure_defense_penalty`）、有效露出入口已就緒（`effective_exposure`，存儲值＋裝備 `exposure_bias` 封頂疊加）；收益側（`sanctified_ward` HOT、`goddess_milk` 推進量）為本設計新增。修女聖袍／聖女聖袍的 `exposure_bias`＋`pleasure_gain`＋`heal_gain` 三欄構成聖職者裝備線；禁慾／束縛系道具在教義上是反教條物品，永不帶光屬性加成 |

## 與相鄰系統的接縫

- **情慾秘術**（見 [情慾秘術分類定位](/lore/skill-trees/sexual-act)）：情慾秘術走 SEXUAL_ACT_REGISTRY 的獨立計數器解鎖，本樹走熟練度系譜，兩軸獨立但共享同一套興奮／高潮期相狀態。教會聖所「邊做愛邊治療」的傳統就是兩條軸線在實務上的疊合。
- **戰鬥中性行為／性高潮系統**：性行為在戰鬥中可執行（pleasure／sexual_counter／sexual_event 等效果字串走既有 action 管線，性脅迫掃描同時覆蓋戰內戰外）；高潮的延長與結束由世界時鐘的 `climax_settlement_action` 結算。`blessed_climax` 完全複用這條管線：觸發（強制 pleasure 推進，同 `divine_pleasure_max` 路徑）、鎖定（combat modifier）、解除（climax_ends → 餘韻）都是現成機制，無需新增狀態。
- **避孕（攝理之術）**：教會設定中以光魔法避孕的實用雜技刻意**不立節點**——它是聖所日常的學徒位階應用，不是戰鬥分支；若日後要機制化，歸屬 [雜學秘術](/lore/skill-trees/utility)。
- **森林精靈**：親和光的斐歐恩族學本樹最快（×1.1 親和 × ×10 學習倍率，人類見頂 556 次的節點她們 46 次見頂），且其全族無羞恥的性文化讓〔聖禮〕節點零摩擦啟動——呼應「教會教義是女神血脈流露之性風俗的人類翻版」這條世界觀真相；也呼應聖職體系對精靈的雙重態度：她們是活教義，也是同行會嫉妒的存在。

`light_mastery`（光屬性精通）作為 PASSIVE 精通被動，不是系譜節點：擁有它會整體強化本樹所有節點的威力係數表現，取得方式是劇情授予或匯入，而非使用累計。
