# 魔法技能體系

本篇是 [世界觀總覽](/lore/overview) 的延伸專篇，將原始設定〈魔法體系〉一節（元素魔法、神之秘法、位階、魔法道具）展開為完整的技能體系樹，並補上原始設定沒有明文交代、但角色與規則已經隱含的空白：身體強化的倍率位階、天賦異能的定位、雜學秘術的邊界，以及各分支之間如何構成一個自洽的整體。

**本篇與 [技能系譜設計](/lore/skill-trees/index) 是同一份魔法設計的兩個部分，共同構成權威來源。** 本篇負責世界觀框架、種族親和、屬性哲學與跨系統的整體規則；每個屬性、每個分支底下逐一技能的前置條件、熟練度門檻、資源消耗與威力數值，由 `skill-trees/` 底下的專頁詳列。`world/skills/registry.py` 現行只實作了火屬性一條系譜作為機械驗證用的雛型，其餘內容尚未落地——下一階段的程式實作要以本篇與 `skill-trees/` 為準寫入程式碼，而不是反過來。新增或調整魔法的程式流程請依循 [新增魔法指南](/development/adding-spells)。

〔世界觀延伸〕標記的內容是本篇新增、原始設定未明文記載的補完，用來填補「原始世界觀只描述了一部份的世界」的空白；未標記的內容則是既有設定的展開說明。

## 1. 魔力論：力量從何而來

### 1.1 兩種魔力

元素魔法的原理是「調和體內魔力與世界魔力，引發元素現象」。這句話背後隱含兩種魔力：

- **體內魔力（內息）**：每個生物與生俱來、儲存於自身的魔力總量，即角色數值中的「魔力值」。消耗後需要休息、藥劑或〔世界觀延伸〕冥想來恢復。
- **世界魔力（潮汐）**：瀰漫於大陸各處、密度並不均勻的環境魔力場。施法者的體內魔力只是「引信」，真正構成火球、水牆、雷擊的能量絕大部分來自世界魔力——這也是為什麼獸人（體內魔力稀薄）仍能點燃一簇火苗，而精靈（體內魔力龐大）能召喚足以撼動戰局的災厄級奇蹟：他們引動世界魔力的效率天差地遠。

〔世界觀延伸〕世界魔力並非恆定，各地會隨地脈、季節、月相與迷宮活動出現「魔力潮汐」：迷宮周邊、精靈村落、古代遺跡通常是魔力濃度的「潮汐高點」，施法消耗更低、威力更強；長期爭戰或魔獸暴動後的焦土則會出現「魔力枯竭帶」，數月甚至數年內魔法效果大打折扣。這也是冒險者公會將「探索類」與「討伐類」任務分開計價的暗中理由之一——迷宮探索順帶勘測魔力潮汐，本身就有情報價值。

### 1.2 魔紋顯現

魔力等級達到大師位階以上的施法者，全力施法時皮膚下會浮現淡淡的魔力紋路，顏色對應其主要親和屬性（火橙、水藍、風綠、土棕、雷紫、冰白、光金、暗紫黑）。這是世界魔力透過施法者身體時在血肉與魔力交界處產生的可見痕跡，並非任何種族獨有的異能；賢者與主宰位階者甚至在平靜狀態下也會有極淡的常駐紋路，是辨認高階施法者最直接的方式之一。

### 1.3 施法的形式：從詠唱到意念

魔法並非「想到就會」。位階不是角色整體的等級，而是**每一個法術自己**的資料標籤——一個施法者可能在「火」的系譜裡已經磨練到主宰位階的節點，在「冰」的系譜裡卻連學徒位階都尚未解鎖。位階越高的節點，施法者需要外顯的輔助手段越少：

| 位階 | 施法方式 |
| --- | --- |
| 學徒 | 必須完整詠唱咒語並繪出對應魔法陣，失敗率高，常見於學院初階課程 |
| 術師 | 可省略部分詠唱，以簡化陣型或隨身法杖／飾品作為焦點媒介 |
| 大師 | 僅需短句詠唱或手勢，魔法陣退化為一閃即逝的符文殘影 |
| 賢者 | 半詠唱即可成術，甚至能理解術式原理、自行改造既有魔法 |
| 主宰 | 不拘泥於形式，能量隨意念而動，已然超脫術式框架，理論上無施法失敗的可能 |

施法失敗（尤其是學徒、術師位階越級嘗試高階魔法時）並非單純「沒有效果」，而是魔力逆流灼傷施法者自身、魔法陣崩潰波及周遭，或召喚出的元素現象失控暴走——這是學院教育格外強調紮實基礎的原因，也是〔世界觀延伸〕大陸各國明文禁止「未經認證者私自嘗試大師位階以上魔法」的立法背景。

## 3. 元素魔法

八屬性的基礎定位維持原始設定：火（攻擊性最強）、水（治療與防禦）、風（速度與範圍攻擊）、土（防禦與控制）、雷（高速攻擊）、冰（控制與攻擊）、光（治療與淨化）、暗（詛咒與削弱）。每個屬性各自形成一套從學徒到主宰、共約十個法術的完整位階序列；除了主動法術，每個屬性都有一個被動的「屬性精通」技能，代表施法者對該屬性理解的深化，會提升該屬性所有魔法的威力而非開啟新法術。

每個屬性完整的系譜樹——所有節點的名稱、前置條件、熟練度門檻、資源消耗與威力係數——收錄在 `skill-trees/` 底下的專頁；這裡只交代八個屬性各自的核心哲學：

| 屬性 | 核心哲學 | 完整系譜 |
| --- | --- | --- |
| 火 | 毫不妥協的正面壓制，沒有迂迴的控場效果，一路把傷害推向極限 | [火屬性系譜樹](/lore/skill-trees/fire) |
| 水 | 治療與深海攻控並重，是唯一「越到高階、治療法術威力越接近攻擊法術」的屬性 | [水屬性系譜樹](/lore/skill-trees/water) |
| 土 | 限制敵人的自由，攻擊往往伴隨行動限制而非單純的數字傷害 | [土屬性系譜樹](/lore/skill-trees/earth) |
| 風 | 同時涵蓋攻擊與機動，從一開始就不甘於只是攻擊手段 | [風屬性系譜樹](/lore/skill-trees/wind) |
| 雷 | 先制與連續行動，快人一步是核心定位 | [雷屬性系譜樹](/lore/skill-trees/lightning) |
| 冰 | 與雷互為表裡：雷讓己方更快，冰讓敵方更慢 | [冰屬性系譜樹](/lore/skill-trees/ice) |
| 光 | 光明教會信仰體系在魔法上的直接體現，唯一在最高位階仍保留純輔助定位的屬性 | [光屬性系譜樹](/lore/skill-trees/light) |
| 暗 | 讓敵人先弱下去，削弱、腐蝕、恐懼伴隨每一階的傷害 | [暗屬性系譜樹](/lore/skill-trees/dark) |

### 3.9 元素相生相剋〔世界觀延伸〕

原始設定沒有交代元素之間的關係，僅列出各元素的獨立定位。為了讓戰術選擇更有意義，補上一套四組對立關係的框架，供 GM 敘事與冒險者的戰術判斷使用——**這是敘事與戰術層面的世界觀設定，目前尚未反映在戰鬥數值判定中**，如果日後要落地為傷害加成機制，需另外開 OpenSpec 變更定義：

| 對立組 | 剋制原理 |
| --- | --- |
| 火 ↔ 水 | 水滅火、火蒸水，兩者互相壓制，是最直觀的元素對抗 |
| 風 ↔ 土 | 風蝕土而削弱其防禦，土困風而抵銷其機動優勢 |
| 雷 ↔ 冰 | 雷擊融冰造成範圍傷害擴散，冰能吸收並延遲雷的傳導 |
| 光 ↔ 暗 | 光淨化暗屬性的詛咒效果，暗遮蔽光屬性的偵測與淨化範圍 |

## 4. 神之秘法：唯有神性能觸及的秘術

神之秘法的學習條件是「具備神性」——目前已知只有精靈族具備神性，其他種族完全無法使用。與元素魔法不同，神之秘法「直接干涉世界之理，無視常規規則」，消耗的不是魔力值而是精神力，長時間使用會感到精神疲憊而非魔力枯竭。

現行已知且已系統化的四項秘法：

| 秘法 | 效果概要 |
| --- | --- |
| 神之秘法：時間加速 | 加速或減緩局部區域的時間流動 |
| 神之秘法：空間扭曲 | 扭曲空間，使存在與景物短距離移位重組 |
| 神之秘法：物質轉換 | 改變物質本質，將萬物轉化為其他形態的有限度煉金術 |
| 神之秘法：生命延續 | 延續生命與壽命，並非復活，而是延緩死亡的秘法 |

〔世界觀延伸〕值得注意的是，掛著「神之秘法」之名的技能不見得都被歸類在同一個機制分類之下——「狀態偽裝」與「統御術」雖然也是神之秘法的一種，效果卻分別偏向資訊操作（隱藏真實數值）與能力分享（授予目標部分自身技能效果），因此在技能體系上被歸入「雜學秘術」而非「神之秘法」本身。這反映出神之秘法橫跨戰鬥、資訊、生活各層面的廣度：它不是一種「法術」，而是一整套凌駕於術式規則之上的能力總稱，只是恰好有部分效果的應用場景落在日常而非戰鬥。

一般精靈族花數十年閒暇時間學習神之秘法，但認真鑽研者能一年學成；三個分支對神之秘法的偏好也不盡相同——森林精靈多用於生命延續與治療輔助、黑暗精靈多用於物質轉換與戰鬥強化、幻童精靈則是唯一天生親和全部四項且被認為最有機會開發出「未知第五項秘法」的分支。

四項秘法各自的完整系譜（前置條件、精神力消耗、效果數值）與匯合而成的終極節點，見 [神之秘法系譜樹](/lore/skill-trees/divine-mystery)。

## 5. 身心強化：位階化的身體強化體系〔世界觀延伸〕

原始設定提到人類、獸人、精靈的物理數值差距，也提到「身體強化」技能能將戰鬥力、敏捷、防禦同時提升數十、數百甚至上千倍，卻沒有交代這套倍率體系是怎麼分級的。將現行技能目錄的三個倍率位階對照回原始設定的種族數值後，可以整理出一套完整的位階表：

| 技能位階 | 倍率 | 定位 |
| --- | --- | --- |
| 身體強化·初階 | ×1.2 | 一般冒險者、貴族護衛、正規騎士皆可透過長年訓練習得的基礎強化，效果溫和但幾乎沒有天賦門檻 |
| 身體強化 | ×100 | 需要精靈血統，或長年修煉且擁有極高天賦的人族／獸人強者方能觸及，是精靈族日常戰鬥的基本配備 |
| 身體超強化 | ×1000 | 僅頂尖精靈、或握有特殊天賦（例如轉生帶來的異能）者能達到的極限強化，全大陸屈指可數 |

這套位階直接解釋了原始設定中「精靈身體素質是人類精銳戰士十倍」這句話背後的機制：那個十倍是**未強化的基礎體格差距**，一旦精靈施展身體強化，倍率會在基礎差距之上再相乘，這也是為什麼精靈中的「異數」戰力會與人類、獸人的頂點完全不在同一個量級。

身心強化分支底下還有一系列不直接提升倍率、而是精煉特定戰鬥面向的被動技能：護主本能（強化守護本能）、極限耐力（提升耐力上限）、劍術精通（強化劍術與刀術效果）、精準魔力控制（強化施法精準度）、魔法陣理解（強化對魔法陣的理解運用）、防禦直覺（被動強化防禦）、集中（暫時提升專注與命中）、隨從武藝訓練（提升隨從角色的武藝水準）。這些技能共同構成「不改變施法者能學會什麼，只讓既有能力發揮得更好」的精煉層，與元素魔法、武藝彼此疊加而非取代。這整個分支都是被動持有即生效，沒有人會「使用」防禦直覺或身體強化本身，因此不像元素魔法的主動法術那樣需要靠熟練度解鎖——取得方式是劇情授予、匯入或（人類與獸人的初階身體強化）長年訓練後由學院／部族認可，而非系譜樹上的練習累積。

每個技能具體的取得條件，包括本設計新增的「跨系譜自動授予」規則，見 [身心強化：取得條件一覽](/lore/skill-trees/enhancement)。

## 6. 武藝：融合魔力的近戰流派

武藝分支是體術與元素魔力結合的產物，而非純粹的肉搏技巧。以下是目前已系統化的流派：

- **雙持劍術**：同時揮舞兩把武器的架式，是人類與獸人劍士的共通基礎流派。
- **雙刀流·宗師級**：融合暗屬性魔力的雙刀連擊，是基亞蘭族（黑暗精靈）刀術傳統的巔峰體現，速度足以超越視覺捕捉。
- **光劍架式**：融合光屬性魔力的劍術架式，多見於王國聖騎士團與森林精靈弓箭手轉職的近戰型態。
- **影斬**：潛入闇影後發動的暗屬性斬擊，是黑暗精靈與人類暗殺流派共通的技法根源。

〔世界觀延伸〕三國與各部族的武藝傳承各有側重：帝國以劍術學院的正規劍式為主，講究陣型與團體戰；王國的聖騎士團將光屬性魔力與劍術結合，形成「聖騎士劍術」一系；獸王國各部族口傳身傳，狼人重團隊陣型、熊人重重型武器、兔人重弓術、貓人重暗殺技巧，彼此並不共通，因此獸人戰士的招式往往帶有強烈的部族辨識度；黑暗精靈的刀術則是三大精靈分支中唯一發展出系統化武學傳統的一支，森林精靈雖擅弓術但無固定流派，幻童精靈則幾乎不修習武藝，全副心力放在魔法與神之秘法上。

完整系譜（劍術與雙刀兩條路線、位階詞彙、匯合節點）見 [武藝系譜樹](/lore/skill-trees/martial-arts)。

## 7. 身法：從加速到超越距離

身法分支涵蓋所有形式的移動增益，難度隨手段的「超自然程度」遞增：

| 技法 | 定位 |
| --- | --- |
| 疾風術 / 靜電護體 等自我強化 | 元素魔法底下的速度型自我增益，嚴格說仍是元素魔法的一部分 |
| 飛行術 | 操控風元素飛行，前往遠處的場合，是最基礎的「真正身法」技能 |
| 瞬步 | 以高速步伐瞬間移動至較近的場合，不依賴特定元素親和 |
| 神之秘法：空間扭曲 | 短距離傳送，直接扭曲空間本身，是身法技能樹的終點，唯有神性能觸及 |

這個序列呈現出一條清楚的世界觀邏輯：**從「用魔法加速自己」到「用魔法縮短距離」，最後到「讓空間本身讓步」**——普通施法者終其一生也只能停留在前兩個階段，空間扭曲是少數精靈才有機會掌握的秘法。

每個技法各自的取得條件與力量來源，見 [身法：取得條件一覽](/lore/skill-trees/movement)。

## 8. 天賦異能：無法習得的力量

天賦異能是整個技能樹中唯一「無法主動學習」的分支：它們不是靠修煉獲得，而是與生俱來的種族特質，或因極其罕見的機緣（例如轉生）而被賦予。

- **精靈長壽**：延長生命週期的被動特質，是精靈族與生俱來、無法被其他種族習得的種族天賦。
- **轉生祝福**：目前已知的案例極其稀少，效果因人而異——曾出現過的形式包括加速魔力成長速度、強化戰鬥直覺與預判、精通性魔法領域等，每一種都是單一、獨一無二、無法複製的祝福，而非可選擇的技能。

〔世界觀延伸〕天賦異能的存在，某種程度上解釋了「魔獸與迷宮的真正起源」「精靈族的神秘歷史」這類懸而未決的謎團為何始終無解：如果連神性血脈本身都會偶爾誕生出連精靈長老都無法解釋的異常個體，大陸上顯然還存在著比目前已知範圍更深、更古老的力量規則。獸人與人類是否也有各自的隱性天賦異能（例如獸王血脈的「獸魂共鳴」、王室血脈的政治直覺），目前尚無定論，是留給未來劇情擴充的空間。

已知類型的完整清單與尚未證實的猜想，見 [天賦異能：取得條件一覽](/lore/skill-trees/innate-gift)。

## 9. 雜學秘術：戰鬥之外的魔法應用

雜學秘術收錄不直接用於戰鬥、卻深刻影響日常與社會運作的魔法應用：

- **神之秘法：狀態偽裝**：以神之秘法偽裝自身的外貌與部分能力數值，讓其他人或測量魔導具只能看到被偽裝的數值。這是精靈族得以在人類社會中「低調」行動的關鍵手段，也是公會鑑定制度必須正視的漏洞——理論上沒有任何鑑定手段能看穿神性偽裝。
- **統御術**：授予目標一部分自身技能的效果，是精靈用來扶植、影響甚至操控其他角色能力成長的秘法，效果本質上是一種「單向的能力分享」。

〔世界觀延伸〕雜學秘術不只這兩項：原始設定提及的「附魔」「儲物袋」「鑑定」等魔法道具相關能力，邏輯上也屬於這個分支——它們共同的特徵是「改變資訊或物質的呈現方式，而非直接造成戰鬥效果」。鑑定與儲物已系譜化為新增系譜，見 [雜學秘術系譜樹](/lore/skill-trees/utility)；附魔本身仍待第 13 節〈魔法道具與工藝〉的後續設計。

## 10. 情慾秘術：光明教會與精靈生理交會之處

情慾秘術是一個獨立分類，與光明教會的信仰體系、精靈族的生理特質緊密相關，機制上聚焦於角色互動與狀態效果，因此獨立於「神之秘法」與「元素魔法」之外分類。它的入門技藝任何具備適當信仰或身體條件的角色都能碰觸，但頂點——「性魔法主宰」與「神之秘法：性愛系統」——與神之秘法共用同一道「神性」門檻，因此規則上仍只有精靈族能夠真正登頂：這一分支的存在提醒著整個世界觀一件事，光明教會的性愛核心教義並非單純的風俗描寫，而是有實際魔法效力作為信仰根基。本篇不展開這個分支的敘事細節，相關內容以角色設定與劇情文件為準；本分支在技能體系上的分類位置與解鎖骨架另見 [情慾秘術：系統分類定位](/lore/skill-trees/sexual-act)，同樣不展開招式內容。

## 11. 位階、魔力值與熟練度：三把不同的量尺

「位階」「魔力值」「能不能用某個法術」是三把獨立的量尺，分別回答三個不同的問題：

- **魔力值（魔力）回答「打得多痛、治得多深」**：是與物理戰鬥力、敏捷、防禦同等地位的固定戰鬥屬性，由角色創建時的種族與天賦決定基準區間，之後不會再因為戰鬥、時間流逝而改變——精靈魔力值天生就遠超人類，不是因為精靈更努力練功。
- **熟練度回答「會不會用某個法術」**：每個主動技能都有自己獨立的熟練度計數，只有實際使用該技能才會累積；熟練度達到後續技能宣告的門檻，才會解鎖那個分支節點——詳見 [技能系譜設計](/lore/skill-trees/index)。魔力值再高，沒練過對應的前置技能，一樣打不出更深層的法術。
- **位階稱號（學徒／術師／大師／賢者／主宰）回答「這個法術貴不貴」**：純粹是每個法術自身的 MP 成本資料標籤，用來對照下表的成本帶，不是任何人整體的晉升門檻。

| 位階 | MP 成本帶（單體／範圍） | 定位 |
| --- | --- | --- |
| 學徒 | 10–16 ／ 14–20 | 基礎魔法，任何練過該系譜入口的角色都能負擔 |
| 術師 | 20–28 ／ 26–34 | 實用魔法，穩定冒險者的主力手段 |
| 大師 | 35–48 ／ 45–60 | 強力魔法，開始需要可觀的魔力儲備 |
| 賢者 | 65–85 ／ 80–110 | 戰略級魔法，人類中僅極少數魔力值夠高的個體能連續施放 |
| 主宰 | 120–150 ／ 140–180 | 傳說級魔法，多數人類即使系譜已解鎖也負擔不起 MP |
| 神格 | 180–220 ／ 200–260 | 匯合兩條主宰路線才能觸及的極限型態，見 [技能系譜設計](/lore/skill-trees/index) §4 |

〔世界觀延伸〕魔力值的種族基準區間：人類 5–90、獸人 1–30、精靈 100–900，與原始設定「人類魔法上限 90」「精靈天賦者可達 900」的數字完全一致，差別只在機制——不是靠累積經驗「升等」到 900，而是精靈這個種族的血脈本身就把基準區間訂在那裡；人類即使把系譜樹點滿、每個節點都練到見頂，魔力值依然可能負擔不起一次主宰位階的施放。這正是「究極魔法人類幾乎不可能掌握」真正的機制解釋：不是學不會，而是打不起。

種族之間真正拉開差距的另一個變因是**學習速度**：精靈的熟練度累積速度是人類與獸人的十倍。魔力值天生就高，學習系譜樹的速度又快十倍，兩件事疊加才是精靈全方位凌駕其他種族的真正原因。

〔世界觀延伸〕社會地位上的頭銜（帝國皇家魔法學院授予的「術師」稱號、冒險者公會的位階考核）依然存在，但那是**獨立於系譜解鎖之外的社會制度**——一紙證書證明的是他人認可你的能力，不是你實際能對敵人做什麼。一個從未受過學院教育的精靈可能系譜樹已點到主宰節點，在人類社會的位階制度裡卻什麼頭銜都沒有；反過來，一個學院頒發「大師」證書的人類貴族子弟，也可能因為疏於實戰而在系譜樹上仍停留在術師位階的節點。

## 12. 魔法教育與組織

### 12.1 既有機構

- **帝國皇家魔法學院**：帝國治下規模最大的魔法教育機構，課程從學徒到大師位階皆有系統化教材，畢業典禮授予的「術師」稱號等同准貴族身分的社會確認。
- **王國聖騎士團**：以騎士精神與榮譽為核心，但團內設有光屬性魔法的專門教程，訓練「聖騎士劍術」這類融合光魔法與劍術的複合戰技。
- **獸人部族師徒制**：獸王國沒有正規學院，魔法（多半僅止於點火、照明等學徒位階前段的應用）與武藝一同由部族內的師徒制口傳身授，教學內容因部族而異。
- **精靈自學／口傳**：精靈族沒有正式教育，憑藉超長壽命自然積累知識，或由年長者口傳，神之秘法尤其如此——沒有任何精靈村落設有「秘法學校」。

### 12.2 新增機構〔世界觀延伸〕

原始設定提到「附魔師」「鍊金術」等魔法應用，卻沒有交代培養這些專業人才的組織。補上兩個與冒險者公會平行、同為跨國中立組織的專業協會：

- **魔導士協會**：以「認證施法者位階」與「調停魔法糾紛」為主要職能，總部與冒險者公會同設於帝國首都，但運作完全獨立。學院畢業生若想在畢業後持續獲得官方位階認證（尤其是大師以上），需向協會登記並定期複測，而非只靠學院一次性頒發的稱號。協會同時負責審核「魔法藥劑」「魔法武器」等商品是否符合安全規範，是三國魔法道具貿易能夠互通有無的幕後把關者。
- **附魔師公會**：規模小於魔導士協會，會員多為手工業背景出身、後來鑽研附魔技藝的匠人，總部設於王國聖潔王都（呼應王國「手工業與貿易為主」的產業定位）。公會維護一份「附魔配方」的行會秘傳紀錄，只有正式會員才能取得完整配方，這也是帝國雖然壟斷高端魔法道具市場、卻仍需向王國採購中階附魔半成品的原因。

## 13. 魔法道具與工藝

魔法道具的製作原理是「將魔法固定於物品中」，需要附魔師執行，稀有道具多來自迷宮或神代遺跡而非現代工匠之手。常見道具包括魔法燈、儲物袋（空間魔法）、治療藥劑（煉金術）、附加元素傷害的魔法武器；稀有道具則有飛行斗篷、防禦戒指等迷宮戰利品。

精靈的體液是稀有魔法素材，具有強大魔力，是製作高階魔法道具與藥劑的珍貴原料——這也是精靈與人類社會互動時，即使他們自己毫不在意，人類社會仍會極度謹慎對待這份「贈與」的原因之一。

〔世界觀延伸〕**魔法陣文字系統**：所有元素魔法的詠唱與繪陣都使用一套共通的「陣文」，字形介於幾何圖騰與古老文字之間，據信與精靈古語同源，但已經演化為獨立的書寫系統，不需要理解精靈古語也能學習基礎陣文。陣文可以繪製在紙張、木板、金屬甚至地面上，繪製媒介的持久度與導魔效率直接影響魔法陣的穩定性——這是「附魔」與「單純繪陣施法」的根本差異：附魔是把陣文永久蝕刻進物質結構，繪陣施法則是暫時性的一次性標記。

〔世界觀延伸〕**神代遺跡科技**：少數迷宮深處保存著遠早於三國歷史、甚至早於精靈記憶的遺跡構造，其上的陣文與已知陣文系統有明顯差異，至今無人能完整解讀。冒險者公會將這類遺跡列為「特殊探索類」任務，通常要求隊伍中至少有一名賢者位階以上的施法者隨行，以策安全。

## 15. 禁忌魔法〔世界觀延伸〕

原始設定的暗屬性魔法定位是「詛咒與削弱」，屬於合法且被廣泛教授的元素魔法分支；但世界觀留白處暗示著更深、更危險的力量——三國與冒險者公會、光明教會共同查禁的「禁忌魔法」，包括操控屍體或亡靈的死靈術、以獻祭或痛苦為代價的血咒，以及直接支配他人意志的精神支配術。這些禁忌並非暗屬性魔法的延伸，而是被認為觸碰了神之秘法的邊界卻缺乏神性支撐、只能以殘缺且危險的方式強行複製效果的「偽秘法」。

已知的禁忌魔法典籍多半只存在於神代遺跡深處或早已滅亡的秘密結社殘卷之中，冒險者公會將發現此類典籍列為「緊急類」任務等級，要求立即回報並封存，私自研習者無論種族一律視為重罪。這條世界觀留白同時也是「魔獸與迷宮的真正起源」之謎的其中一種假說切入點——部分學者懷疑，迷宮本身可能就是遠古某次禁忌魔法失控的殘留產物。

## 16. 魔法的未解之謎

延續 [世界觀總覽](/lore/overview) 列出的懸而未決之謎，從魔法角度補充幾個可供未來劇情發展的切入點：

- **陣文的真正起源**：陣文系統與精靈古語同源卻已分化成獨立文字，沒有人（包括精靈）能說清楚陣文究竟是誰、在什麼時候創造的。
- **「第九屬性」傳說**：坊間偶有傳言指出神代遺跡中曾出現無法歸類於現有八屬性的魔力現象，但至今沒有任何實證，也沒有任何在世者宣稱親眼見過——如果傳說為真，它極可能與知識女神的失落知識或迷宮的起源直接相關。
- **禁忌魔法與迷宮的關係**：迷宮是否是遠古禁忌魔法失控的殘留產物，目前只是學者假說，尚無定論。
- **獸人與人類的魔法天花板為何如此接近**：獸人的物理數值遠超人類，唯獨魔法天賦被壓制在極低水準；究竟是天生的種族限制，還是某種被遺忘的歷史事件（例如與神代文明的衝突）所留下的封印，仍是謎團。

這些未解之謎刻意不給出答案，供未來的任務設計、劇情事件與角色成長弧線填入具體內容。
