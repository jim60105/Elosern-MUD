# 魔法技能體系

本篇是 [世界觀總覽](/lore/overview) 的延伸專篇，將原始設定〈魔法體系〉一節（元素魔法、神之秘法、位階、魔法道具）展開為完整的技能體系樹，並補上原始設定沒有明文交代、但角色與規則已經隱含的空白：身體強化的倍率位階、天賦異能的定位、雜學秘術的邊界，以及各分支之間如何構成一個自洽的整體。

**本篇與 [技能系譜設計](/lore/skill-trees/index) 是同一份魔法設計的兩個部分，共同構成權威來源。** 本篇負責世界觀框架、種族親和、屬性哲學與跨系統的整體規則；每個屬性、每個分支底下逐一技能的前置條件、熟練度門檻、資源消耗與威力數值，由 `skill-trees/` 底下的專頁詳列。`world/skills/registry.py` 現行只實作了火屬性一條系譜作為機械驗證用的雛型，其餘內容尚未落地。下一階段的程式實作要以本篇與 `skill-trees/` 為準寫入程式碼，順序不可顛倒。新增或調整魔法的程式流程請依循 [新增魔法指南](/development/adding-spells)。

## 1. 魔力論：力量從何而來

元素魔法的原理是「調和體內魔力與世界魔力，引發元素現象」。這句話背後隱含兩種魔力：

- **體內魔力**：每個生物與生俱來、儲存於自身的魔力總量，即角色數值中的「魔力值」。消耗後需要休息或藥劑來恢復。
- **世界魔力**：瀰漫於大陸各處、密度並不均勻的環境魔力場。施法者的體內魔力只是「引信」，真正構成火球、水牆、雷擊的能量絕大部分來自世界魔力。獸人（體內魔力稀薄）仍能點燃一簇火苗，精靈（體內魔力龐大）則能召喚足以撼動戰局的災厄級奇蹟，兩者引動世界魔力的效率天差地遠。

## 3. 元素魔法

八屬性的基礎定位維持原始設定：火（攻擊性最強）、水（治療與防禦）、風（速度與範圍攻擊）、土（防禦與控制）、雷（高速攻擊）、冰（控制與攻擊）、光（治療與淨化）、暗（詛咒與削弱）。每個屬性各自形成一套從學徒到主宰、共約十個法術的完整位階序列；除了主動法術，每個屬性都有一個被動的「屬性精通」技能，代表施法者對該屬性理解的深化，會提升該屬性所有魔法的威力而非開啟新法術。

每個屬性完整的系譜樹（所有節點的名稱、前置條件、熟練度門檻、資源消耗與威力係數）收錄在 `skill-trees/` 底下的專頁，這裡只交代八個屬性各自的核心哲學：

| 屬性 | 核心哲學 | 完整系譜 |
| --- | --- | --- |
| 火 | 毫不妥協的正面壓制，沒有迂迴的控場效果，一路把傷害推向極限 | [火屬性系譜樹](/lore/skill-trees/fire) |
| 水 | 治療與深海攻控並重，是唯一「越到高階、治療法術威力越接近攻擊法術」的屬性 | [水屬性系譜樹](/lore/skill-trees/water) |
| 土 | 限制敵人的自由，攻擊多伴隨行動限制，較少以單純的數字傷害呈現 | [土屬性系譜樹](/lore/skill-trees/earth) |
| 風 | 同時涵蓋攻擊與機動，從一開始就不甘於只是攻擊手段 | [風屬性系譜樹](/lore/skill-trees/wind) |
| 雷 | 先制與連續行動，快人一步是核心定位 | [雷屬性系譜樹](/lore/skill-trees/lightning) |
| 冰 | 與雷互為表裡：雷讓己方更快，冰讓敵方更慢 | [冰屬性系譜樹](/lore/skill-trees/ice) |
| 光 | 雙面屬性：對任何魔法使是正經的治療與淨化之術；對聖職者則是與性之歡愉深度連動的信仰魔法，性興奮越接近女神、回復越強，高潮即極大回復，唯一在最高位階仍保留純輔助定位的屬性 | [光屬性系譜樹](/lore/skill-trees/light) |
| 暗 | 讓敵人先弱下去，削弱、腐蝕、恐懼伴隨每一階的傷害 | [暗屬性系譜樹](/lore/skill-trees/dark) |

### 3.9 元素相生相剋

原始設定沒有交代元素之間的關係，僅列出各元素的獨立定位。為了讓戰術選擇更有意義，補上一套四組對立關係的框架，供 GM 敘事與冒險者的戰術判斷使用。**這是敘事與戰術層面的世界觀設定，目前未反映在戰鬥數值判定中**：

| 對立組 | 剋制原理 |
| --- | --- |
| 火 ↔ 水 | 水滅火、火蒸水，兩者互相壓制，是最直觀的元素對抗 |
| 風 ↔ 土 | 風蝕土而削弱其防禦，土困風而抵銷其機動優勢 |
| 雷 ↔ 冰 | 雷擊融冰造成範圍傷害擴散，冰能吸收並延遲雷的傳導 |
| 光 ↔ 暗 | 光淨化暗屬性的詛咒效果，暗遮蔽光屬性的偵測與淨化範圍 |

## 4. 神之秘法：唯有神性能觸及的秘術

神之秘法的學習條件是「具備神性」，目前已知只有精靈族具備神性，其他種族完全無法使用。與元素魔法不同，神之秘法「直接干涉世界之理，無視常規規則」，消耗的是精神力，魔力值不受影響，長時間使用會感到精神疲憊、不會出現魔力枯竭。

**神之秘法是一個開放類別。** 設定上它沒有已知上限，下列四項只是「常見且已被系統化傳承」的招式體系，供所有具備神性的精靈學習；類別本身隨時可能出現新的秘法，未來也將視劇情與規則需要持續擴充。更關鍵的是，神之秘法在設定上是精靈**隨心所欲**使用的能力：除了這些共通的招式體系，個別精靈也各自開發出只屬於自己的獨創體系，最知名的例子就是悠奈・玄夜獨自研發並使用的「神之秘法：性愛系統」（見第 10 節）。獨創體系不進入共通系譜樹，其解鎖由各自機制的把關規則負責。

現行常見且已系統化的四項秘法：

| 秘法 | 效果概要 |
| --- | --- |
| 神之秘法：時間加速 | 加速或減緩局部區域的時間流動 |
| 神之秘法：空間扭曲 | 扭曲空間，使存在與景物短距離移位重組 |
| 神之秘法：物質轉換 | 改變物質本質，將萬物轉化為其他形態的有限度煉金術 |
| 神之秘法：生命延續 | 延續生命與壽命、延緩死亡的秘法，不含復活效果 |

〔世界觀延伸〕神之秘法橫跨戰鬥、資訊、生活各層面，是一整套凌駕於術式規則之上的能力總稱，涵蓋的遠不止單一「法術」。「狀態偽裝」（資訊操作：隱藏真實數值）與「統御術」（能力分享：授予目標部分自身技能效果）都是貨真價實的神之秘法，只是結構上是**單一節點**的形態。神之秘法不一定要成「樹」，一招即完整是完全可以合理的結構，因此它們沒有深化階梯，取得即可用。唯一掛著神之秘法之名、機制分類卻不在神之秘法分支之下的是情慾秘術中的性愛系統系招式（見第 10 節），那屬於機械實作的分桶方式，不改變它們在世界觀上屬於神之秘法的事實。

一般精靈族花數十年閒暇時間學習神之秘法，但認真鑽研者能一年學成；三個分支對神之秘法的偏好也不盡相同，森林精靈多用於生命延續與治療輔助、黑暗精靈多用於物質轉換與戰鬥強化、幻童精靈則是唯一天生親和全部四項共通秘法、且被認為最有機會開發出全新秘法的分支。

四項共通秘法各自的完整系譜（前置條件、精神力消耗、效果數值）與匯合而成的終極節點，見 [神之秘法系譜樹](/lore/skill-trees/divine-mystery)；個別精靈的獨創體系（如性愛系統）不掛在該系譜樹下。

## 5. 身心強化：位階化的身體強化體系〔世界觀延伸〕

原始設定提到人類、獸人、精靈的物理數值差距，也提到「身體強化」技能能將戰鬥力、敏捷、防禦同時提升數十、數百甚至上千倍，卻沒有交代這套倍率體系是怎麼分級的。將現行技能目錄的三個倍率位階對照回原始設定的種族數值後，可以整理出一套完整的位階表：

| 技能位階 | 倍率 | 定位 |
| --- | --- | --- |
| 身體強化·初階 | ×1.2 | 一般冒險者、貴族護衛、正規騎士皆可透過長年訓練習得的基礎強化，效果溫和但幾乎沒有天賦門檻 |
| 身體強化 | ×100 | 需要精靈血統，或長年修煉且擁有極高天賦的人族／獸人強者方能觸及，是精靈族日常戰鬥的基本配備 |
| 身體超強化 | ×1000 | 僅頂尖精靈、或握有特殊天賦（例如轉生帶來的異能）者能達到的極限強化，全大陸屈指可數 |

這套位階直接解釋了原始設定中「精靈身體素質是人類精銳戰士十倍」這句話背後的機制。那個十倍是**未強化的基礎體格差距**，一旦精靈施展身體強化，倍率會在基礎差距之上再相乘，這也是為什麼精靈中的「異數」戰力會與人類、獸人的頂點完全不在同一個量級。

身心強化分支底下還有一系列不直接提升倍率、只在特定戰鬥面向上精煉效果的被動技能，包括護主本能（強化守護本能）、極限耐力（提升耐力上限）、劍術精通（強化劍術與刀術效果）、精準魔力控制（強化施法精準度）、魔法陣理解（強化對魔法陣的理解運用）、防禦直覺（被動強化防禦）、集中（暫時提升專注與命中）、隨從武藝訓練（提升隨從角色的武藝水準）。這些技能共同構成「不改變施法者能學會什麼，只讓既有能力發揮得更好」的精煉層，與元素魔法、武藝彼此疊加而非取代。這整個分支都是被動持有即生效，沒有人會「使用」防禦直覺或身體強化本身，因此不像元素魔法的主動法術那樣需要靠熟練度解鎖。取得方式是劇情授予、匯入或（人類與獸人的初階身體強化）長年訓練後由學院／部族認可，而非系譜樹上的練習累積。

每個技能具體的取得條件，包括本設計新增的「跨系譜自動授予」規則，見 [身心強化：取得條件一覽](/lore/skill-trees/enhancement)。

## 6. 武藝：融合魔力的近戰流派

武藝分支是體術與元素魔力結合的產物，而非純粹的肉搏技巧。以下是目前已系統化的流派：

- **雙持劍術**：同時揮舞兩把武器的架式，是人類與獸人劍士的共通基礎流派。
- **雙刀流·宗師級**：融合暗屬性魔力的雙刀連擊，是基亞蘭族（黑暗精靈）刀術傳統的巔峰體現，速度足以超越視覺捕捉。
- **光劍架式**：融合光屬性魔力的劍術架式，多見於王國聖騎士團與森林精靈弓箭手轉職的近戰型態。
- **影斬**：潛入闇影後發動的暗屬性斬擊，是黑暗精靈與人類暗殺流派共通的技法根源。

〔世界觀延伸〕三國與各部族的武藝傳承各有側重，帝國以劍術學院的正規劍式為主，講究陣型與團體戰；王國的聖騎士團將光屬性魔力與劍術結合，形成「聖騎士劍術」一系；獸王國各部族口傳身傳，狼人重團隊陣型、熊人重重型武器、兔人重弓術、貓人重暗殺技巧，彼此並不共通，因此獸人戰士的招式會帶有強烈的部族辨識度；黑暗精靈的刀術則是三大精靈分支中唯一發展出系統化武學傳統的一支，森林精靈雖擅弓術但無固定流派，幻童精靈則幾乎不修習武藝，全副心力放在魔法與神之秘法上。

完整系譜（劍術與雙刀兩條路線、位階詞彙、匯合節點）見 [武藝系譜樹](/lore/skill-trees/martial-arts)。

## 7. 身法：從加速到超越距離

身法分支涵蓋所有形式的移動增益，難度隨手段的「超自然程度」遞增：

| 技法 | 定位 |
| --- | --- |
| 疾風術 / 靜電護體 等自我強化 | 元素魔法底下的速度型自我增益，嚴格說仍是元素魔法的一部分 |
| 飛行術 | 操控風元素飛行，前往遠處的場合，是最基礎的「真正身法」技能 |
| 瞬步 | 以高速步伐瞬間移動至較近的場合，不依賴特定元素親和 |
| 神之秘法：空間扭曲 | 短距離傳送，直接扭曲空間本身，是身法技能樹的終點，唯有神性能觸及 |

這個序列呈現出一條清楚的世界觀邏輯：**從「用魔法加速自己」到「用魔法縮短距離」，最後到「讓空間本身讓步」**。普通施法者終其一生也只能停留在前兩個階段，空間扭曲是少數精靈才有機會掌握的秘法。

每個技法各自的取得條件與力量來源，見 [身法：取得條件一覽](/lore/skill-trees/movement)。

## 8. 天賦異能：無法習得的力量

天賦異能是整個技能樹中唯一「無法主動學習」的分支。它們的來源有兩種，一是與生俱來的種族特質，二是因極其罕見的機緣（例如轉生）而被賦予。

- **精靈長壽**：延長生命週期的被動特質，是精靈族與生俱來、無法被其他種族習得的種族天賦。
- **轉生祝福**：目前已知的案例極其稀少，效果因人而異，曾出現過的形式包括加速魔力成長速度、強化戰鬥直覺與預判、精通性魔法領域等，每一種都是單一、獨一無二、無法複製的祝福，無法由使用者挑選。

〔世界觀延伸〕天賦異能的存在，為「魔獸與迷宮的真正起源」「精靈族的神秘歷史」這類懸而未決的謎團提供了一種可能的解釋。如果連神性血脈本身都會偶爾誕生出連精靈長老都無法解釋的異常個體，大陸上顯然還存在著比目前已知範圍更深、更古老的力量規則。獸人與人類是否也有各自的隱性天賦異能（例如獸王血脈的「獸魂共鳴」、王室血脈的政治直覺），目前尚無定論，是留給未來劇情擴充的空間。

已知類型的完整清單與尚未證實的猜想，見 [天賦異能：取得條件一覽](/lore/skill-trees/innate-gift)。

## 9. 雜學秘術：戰鬥之外的魔法應用

雜學秘術收錄不直接用於戰鬥、卻深刻影響日常與社會運作的魔法應用。它的邊界是「**技術而非秘法**」，不要求神性、三種族都能學習、改變資訊或物質的呈現方式而非直接造成戰鬥效果。目前已系譜化的內容是鑑定與儲物兩條小型系譜，見 [雜學秘術系譜樹](/lore/skill-trees/utility)。

〔世界觀延伸〕原始設定提及的「附魔」「儲物袋」「鑑定」等魔法道具相關能力，邏輯上都屬於這個分支；附魔本身仍待第 13 節〈魔法道具與工藝〉的後續設計。過去曾被歸入本分支的「狀態偽裝」與「統御術」應歸類為神之秘法的單節點形態（見第 4 節），它們要求神性、也只有神性能用。

## 10. 情慾秘術：光明教會與精靈生理交會之處

情慾秘術是一個獨立分類，與光明教會的信仰體系、精靈族的生理特質緊密相關，機制上聚焦於角色互動與狀態效果，因此獨立於「神之秘法」與「元素魔法」之外分類。它的入門技藝任何具備適當信仰或身體條件的角色都能碰觸，但頂點的「性魔法主宰」與「神之秘法：性愛系統」與神之秘法共用同一道「神性」門檻，因此規則上仍只有精靈族能夠真正登頂。這一分支的存在提醒著整個世界觀一件事，光明教會的性愛核心教義有實際魔法效力作為信仰根基，遠不止風俗描寫。本篇不展開這個分支的敘事細節，相關內容以角色設定與劇情文件為準；本分支在技能體系上的分類位置與解鎖骨架另見 [情慾秘術：系統分類定位](/lore/skill-trees/sexual-act)，同樣不展開招式內容。

## 11. 位階、魔力值與熟練度：三把不同的量尺

「位階」「魔力值」「能不能用某個法術」是三把獨立的量尺，分別回答三個不同的問題：

- **魔力值（magic_power）回答「打得多痛、治得多深」**：是與物理戰鬥力、敏捷、防禦同等地位的固定戰鬥屬性，由角色創建時的種族與血統決定基準區間，之後不會再因為戰鬥、時間流逝而改變。
- **熟練度回答「會不會用某個法術」**：每個主動技能都有自己獨立的熟練度計數，只有實際使用該技能才會累積；熟練度達到後續技能宣告的門檻，才會解鎖那個分支節點，詳見 [技能系譜設計]
- **位階稱號（學徒／術師／大師／賢者／主宰）回答「這個法術貴不貴」**：純粹是每個法術自身的 MP 成本資料標籤，用來對照下表的成本帶。

| 位階 | MP 成本帶（單體／範圍） | 定位 |
| --- | --- | --- |
| 學徒 | 10–16 ／ 14–20 | 基礎魔法，任何練過該系譜入口的角色都能負擔 |
| 術師 | 20–28 ／ 26–34 | 實用魔法，穩定冒險者的主力手段 |
| 大師 | 35–48 ／ 45–60 | 強力魔法，開始需要可觀的魔力儲備 |
| 賢者 | 65–85 ／ 80–110 | 戰略級魔法，人類中僅極少數魔力值夠高的個體能連續施放 |
| 主宰 | 120–150 ／ 140–180 | 傳說級魔法，多數人類即使系譜已解鎖也負擔不起 MP |
| 神格 | 180–220 ／ 200–260 | 匯合兩條主宰路線才能觸及的極限型態，見 [技能系譜設計](/lore/skill-trees/index) §4 |

魔力值的種族基準區間：人類 5–90、獸人 1–30、精靈 100–900（其中一般精靈落在 100–500，500 以上即是所稱的「異數」）。

「究極魔法人類幾乎不可能掌握」的機制解釋要拆成兩半。**魔力值（威力面）**：人類的傷害上限被 magic_power ≤ 90 封死，就算解鎖並付得起主宰節點，一發焚世終焰打出的也只是魔力值 90 倍乘威力係數的數字，解鎖並不會補足威力。**MP 池（可付面）**：人類 MP 池約 100–200（王族血脈 120–220），主宰位階 120–180 的單發成本勉強付得起一次，之後就得靠休息或藥劑回充，連續施放完全不存在；精靈的 MP 池固定為一萬，任何位階的成本帶對他們都近似免費。獸人的 MP 池只有 30–50，賢者位階的成本（65 起）對他們是字面上的天文數字，這就是獸人魔法止步於學徒位階前段的機制本質。

種族之間真正拉開差距的另一個變因是**學習速度**，精靈的熟練度累積速度是人類與獸人的十倍。魔力值天生就高，學習系譜樹的速度又快十倍，兩件事疊加才是精靈全方位凌駕其他種族的真正原因。

社會地位上的頭銜（帝國皇家魔法學院授予的「術師」稱號、冒險者公會的位階考核）依然存在，但那是**獨立於系譜解鎖之外的社會制度**。一紙證書證明的是他人認可你的能力，不是你實際能對敵人做什麼。一個從未受過學院教育的精靈可能系譜樹已點到主宰節點，在人類社會的位階制度裡卻什麼頭銜都沒有；反過來，一個學院頒發「大師」證書的人類貴族子弟，也可能因為疏於實戰而在系譜樹上仍停留在術師位階的節點。

## 12. 魔法教育與組織

### 12.1 既有機構

- **帝國皇家魔法學院**：帝國治下規模最大的魔法教育機構，課程從學徒到大師位階皆有系統化教材，畢業典禮授予的「術師」稱號等同准貴族身分的社會確認。
- **王國聖騎士團**：王國冠下的精銳騎士與最高榮銜，以騎士精神與榮譽為核心；團員的授劍禮在聖潔王都主教座堂舉行、由光明教會聖座主祭祝禱，「聖騎士」之名由此而來，但團的指揮權與人事全屬王國。團內設有光屬性魔法的專門指南，訓練「聖騎士劍術」這類融合光魔法與劍術的複合戰技。
- **獸人部族師徒制**：獸王國沒有正規學院，魔法（多半僅止於點火、照明等學徒位階前段的應用）與武藝一同由部族內的師徒制口傳身授，教學內容因部族而異。
- **精靈自學／口傳**：精靈族沒有正式教育，憑藉超長壽命自然積累知識，或由年長者口傳，神之秘法尤其如此，沒有任何精靈村落設有「秘法學校」。

### 12.2 新增機構

原始設定提到「附魔師」「鍊金術」等魔法應用，卻沒有交代培養這些專業人才的組織。補上兩個與冒險者公會平行、同為跨國中立組織的專業協會：

- **魔導士協會**：以「認證施法者位階」與「調停魔法糾紛」為主要職能，總部與冒險者公會同設於帝國首都，但運作完全獨立。學院畢業生若想在畢業後持續獲得官方位階認證（尤其是大師以上），需向協會登記並定期複測，而非只靠學院一次性頒發的稱號。協會同時負責審核「魔法藥劑」「魔法武器」等商品是否符合安全規範，是三國魔法道具貿易能夠互通有無的幕後把關者。
- **附魔師公會**：規模小於魔導士協會，會員多為手工業背景出身、後來鑽研附魔技藝的匠人，總部設於王國聖潔王都（呼應王國「手工業與貿易為主」的產業定位）。公會維護一份「附魔配方」的行會秘傳紀錄，只有正式會員才能取得完整配方，這也是帝國雖然壟斷高端魔法道具市場、卻仍需向王國採購中階附魔半成品的原因。

## 13. 魔法道具與工藝

魔法道具的製作原理是「將魔法固定於物品中」，需要附魔師執行，稀有道具多來自迷宮或神代遺跡而非現代工匠之手。常見道具包括魔法燈、儲物袋（空間魔法）、治療藥劑（煉金術）、附加元素傷害的魔法武器；稀有道具則有飛行斗篷、防禦戒指等迷宮戰利品。

精靈的體液是稀有魔法素材，具有強大魔力，是製作高階魔法道具與藥劑的珍貴原料。這也是精靈與人類社會互動時，即使他們自己毫不在意，人類社會仍會極度謹慎對待這份「贈與」的原因之一。

**魔法陣文字系統**：所有元素魔法的詠唱與繪陣都使用一套共通的「陣文」，字形介於幾何圖騰與古老文字之間，據信與精靈古語同源，但已經演化為獨立的書寫系統，不需要理解精靈古語也能學習基礎陣文。陣文可以繪製在紙張、木板、金屬甚至地面上，繪製媒介的持久度與導魔效率直接影響魔法陣的穩定性。「附魔」與「單純繪陣施法」的根本差異在於，附魔是把陣文永久蝕刻進物質結構，繪陣施法則是暫時性的一次性標記。

**神代遺跡科技**：少數迷宮深處保存著遠早於三國歷史、甚至早於精靈記憶的遺跡構造，其上的陣文與已知陣文系統有明顯差異，至今無人能完整解讀。冒險者公會將這類遺跡列為「特殊探索類」任務，通常要求隊伍中至少有一名賢者位階以上的施法者隨行，以策安全。

## 15. 江湖術士與假貨市場

暗屬性魔法合法且被廣泛教授（見第 3 節），而真正讓三國官府、冒險者公會與魔導士協會三隻手一起按著的其實是**假貨**，與黑暗力量無關。每個時代都有人想賣「不需要十年苦修也能獲得魔法」的東西，於是有了江湖術士與假貨市場這條灰色產業鏈。

產業鏈的明星商品包括：標著「附魔」卻只會半夜自己發光閃瞎室友的劣質魔法燈、宣稱內含空間魔法實際只是夾層暗格的儲物袋、把學徒位階火苗術包成「龍焰項鏈」的飾品行貨，以及流通最廣的硬通貨**冒牌典籍**，以「禁忌魔法」「神代秘傳」名目高價販售、內容多半是陣文字母表加上幾頁烹飪筆記的裝幀精品。江湖術士本人則多半是考不上學院的落第生，畢生代表作是讓顧客以為自己的掃帚變輕了（物理）。

這個市場需要三個現實支柱才轉得動，而它們全都是既有系統：

- **鑑定系譜是天然剋星**（見 [雜學秘術系譜樹](/lore/skill-trees/utility)）：`detailed_appraisal` 的存在讓「當面鑑定、假貨現形」成為市集日常；術士們的反制則是雇托兒、流動擺攤、以及在攤位掛上「本店概不保證魔法效力」的免責小字。
- **魔導士協會的安全規範是執法後盾**（見第 12.2 節）：魔法道具上市前的安全審核本就歸協會，假貨被查獲的標準流程是沒收、罰款、登報。協會公布的「不合格商品黑名單」與「沒救了術士名單」並列，是酒館閒談的固定笑料。
- **附魔師公會是最大被害者也是最大受益者**（見第 12.2 節）：每一起假貨風暴都是正牌公會免費的公關廣告，「認明公會會員鋼印」的口號因此越喊越響。

冒險者公會的「緊急類」任務等級保留原職，實務內容多數就是查緝大型假貨案：批量售假的窩點、會真的炸的劣質魔法武器、以及把整條街的門牌都搞成空間坐標的失敗儲物袋。

至於「禁忌魔法是否真的存在過」，答案是沒有人拿得出證據，號稱禁忌典籍的東西每年被查獲幾十本，真正運作過的一本也沒有。這個空白屬於第 16 節的未解之謎，與現行規則無關。

## 16. 魔法的未解之謎

延續 [世界觀總覽](/lore/overview) 列出的懸而未決之謎，從魔法角度補充幾個可供未來劇情發展的切入點：

- **陣文的真正起源**：陣文系統與精靈古語同源卻已分化成獨立文字，沒有人（包括精靈）能查明陣文究竟是誰、在什麼時候創造的。
- **「第九屬性」傳說**：坊間偶有傳言指出神代遺跡中曾出現無法歸類於現有八屬性的魔力現象，但至今沒有任何實證，也沒有任何在世者宣稱親眼見過。如果傳說為真，它極可能與知識女神的失落知識或迷宮的起源直接相關。
- **「禁忌魔法」是否真的存在過**：市面上號稱禁忌典籍的假貨年年被查獲（見第 15 節），真正運作過的一本也沒有。有學者堅持，神代遺跡最深處的某些構造明顯超出八屬性的已知框架，迷宮甚至可能是遠古某次失敗實驗的殘留產物。這個假說既認真又好笑：它等於宣稱全大陸的冒險者業建立在某人千年前的一次闖禍之上。支持它的學者人數不多，但每個都辯才無礙。
- **獸人與人類的魔法天花板為何如此接近**：獸人的物理數值遠超人類，唯獨魔法天賦被壓制在極低水準；究竟是天生的種族限制，還是某種被遺忘的歷史事件（例如與神代文明的衝突）所留下的封印，仍是謎團。

這些未解之謎刻意不給出答案，供未來的任務設計、劇情事件與角色成長弧線填入具體內容。
