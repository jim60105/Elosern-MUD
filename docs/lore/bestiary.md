**內容核准日期：**2026-10-05。本次核准六種物種的核心設定與十二個變體方向，不包含能力數值、最終公會評級或技能實作。低階與中階是本批核准的粗略分類，不能直接推導個體能力或整份委託的階級。

本篇是內容設定，不宣告物種登錄表、生成配置、技能效果或物種圖片已實作。分級示例與測試資料中的其他名稱，不會因本篇發布而成為核准物種。

## 低階魔物

### 穗鳴雀

**原型與棲地。**麻雀類的小型群居鳥，生活於東部平原的田埂、灌木與收穫後的農地。

**特殊生態。**啄食成熟穀物前，族群會發出短促而整齊的鳴聲，接著以微弱風屬性氣流震落乾燥穀粒。穗間響起的沙沙聲，是農民辨認牠們的線索。牠們造成的麻煩集中於收穫期；田地仍能正常耕作，但反覆造訪的族群會損耗尚未收起的穀物。

**能力邊界。**濕穀與牢固的未熟穗不易受影響。牠們無法掀翻糧車、吹倒作物，也不具備大範圍風暴能力。

| 變體 | 核准方向 |
| --- | --- |
| 啄穗型 | 普通版本，分散覓食 |
| 領群型 | 以鳴聲協調同伴，從不同方向干擾驅趕者 |

**委託背景示例。**收穫已近尾聲，東側田區每天清晨仍有成群穗鳴雀來訪。農戶請公會處理持續侵入的族群，以免今年最後一批穀物留不下來。

### 潮燈蟹

**原型與棲地。**近岸蟹類，棲息於兩側海岸的礁隙、潮池與港外灘地。

**特殊生態。**背甲上的發光斑紋會追隨附近燈光的明暗節奏。沿岸居民知道牠們會聚集在魔法燈附近，漁人偶爾將牠們當成潮池的位置標記。大量聚集時，不熟悉港口的小船可能誤判岸邊訊號；靠近礁洞的人也可能受到螯足攻擊。

**能力邊界。**牠們只能重現已有光源的節奏，不能製造幻覺或偽裝物體。發光不等於治療能力，也不表示牠們掌握光屬性治療術。

| 變體 | 核准方向 |
| --- | --- |
| 灘行型 | 普通版本，遇人多半退避 |
| 守礁型 | 占據狹窄洞口，利用地形保護族群 |

**委託背景示例。**港外的候船燈附近聚集了一批潮燈蟹，已有夜歸小船認錯泊岸方向。碼頭請公會清理這處聚集地，恢復燈號辨識。

### 築埂兔

**原型與棲地。**穴居兔類，生活於平原邊緣與丘陵的鬆土帶。

**特殊生態。**牠們以土屬性力量壓實巢壁，將挖出的土築成低矮環埂。居民從一圈圈異常牢固的小土埂辨認巢穴；普通雨水不容易沖散，因此棄置巢穴也會留下痕跡。族群沿灌溉渠築巢時，土埂可能堵住分水口，坑洞則妨礙農具與牲畜通行。

**能力邊界。**牠們只能處理巢穴周圍的鬆土，無法鑽穿岩盤、城牆或石造基礎。洞道提供正常的逃離路線，不構成瞬間移動。

| 變體 | 核准方向 |
| --- | --- |
| 掘巢型 | 普通版本，依靠洞道逃避 |
| 護巢型 | 加固入口，在窄處阻擋侵入者 |

**委託背景示例。**兩戶農家原以為渠水不足是分水爭議，查找後才發現分水口旁有築埂兔巢。公會受託處理占據渠岸的族群，讓灌溉恢復。

## 中階魔物

### 岩響山羊

**原型與棲地。**山羊類魔獸，生活於西部丘陵的岩坡、偏遠採石地與山麓。

**特殊生態。**牠們落足前會用角敲擊岩面，辨認裂隙與鬆動岩層。遇到威脅時，可以沿接觸的岩面傳出土屬性脈動，使原本已鬆動的碎石滑落。採石工人會留意牠們的敲岩聲，因為族群常出現在不穩定岩坡附近；牠們占據狹窄運料路線時，便形成難以繞過的威脅。

**能力邊界。**脈動無法粉碎完整岩盤，不會造成大範圍地震。地形與既有鬆石是能力成立的重要條件，不能將牠們描述為隨處都能引發同等規模的崩塌。

| 變體 | 核准方向 |
| --- | --- |
| 踏崖型 | 普通版本，偏向逃往高處 |
| 守隘型 | 守住岩坡入口，將衝撞與落石結合 |

**委託背景示例。**採石場的運料路被岩響山羊占據。工人能聽見上方敲岩聲，卻不敢再推車通過。業主請公會處理守路個體，重新開通運料線。

### 霧鬃山貓

**原型與棲地。**山貓類的獨居獵食者，活動於西北高地森林與潮濕山谷。

**特殊生態。**頸側長毛隨牠引動的微弱氣流展開，使既有霧氣沿身側聚集，干擾獵物判斷接近方向。牠主要捕食林中動物；部分個體會在晨霧中跟隨馱獸隊伍，等待落單動物，因此與部族獵人及山道運輸發生衝突。

**能力邊界。**能力依賴既有霧氣，乾燥、無霧的環境中優勢大幅減弱。牠仍有足跡、氣味與聲音，不能完全隱形、製造任意幻覺或瞬間移動。

| 變體 | 核准方向 |
| --- | --- |
| 林伏型 | 普通版本，守候林間獵徑 |
| 獵道型 | 反覆試探隊伍邊緣，避免正面接近完整隊列 |

**委託背景示例。**高地運輸隊連續在晨霧中失去馱獸，獵人找到的足跡始終沿道路外緣移動。部族請公會處理已開始追逐運輸隊的個體。

### 吞潮鱷

**原型與棲地。**大型鱷類，棲息於東南部偏遠河口、濕地與潮汐支流。

**特殊生態。**牠在接觸活物時，可以透過水屬性力量吸取對方的部分魔力。施法者與牠纏鬥時，可能先感到魔力消耗異常，再發現危險。牠仍依靠咬合與伏擊捕食，並非遠距離施法者。

**能力邊界。**能力需要近身接觸，不能隔著整條河抽取魔力，也不會把吸取的魔力轉成傷口治療。此處的吸取對應可消耗的魔力資源，不表示永久降低目標的固定 `magic_power`。具體消耗量與技能效果不在本次核准範圍內。

| 變體 | 核准方向 |
| --- | --- |
| 潛岸型 | 普通版本，守候野生動物渡水處 |
| 守灣型 | 占據有遮蔽的泊岸入口，阻礙小船靠岸 |

**委託背景示例。**河口渡運站的側灣出現吞潮鱷，船員已停用該泊位。一名協助驅趕的法師在接觸後出現異常魔力損失，渡運站因此改向公會求援。

## 使用邊界

物種與變體的真正起源保持未知。描述可觀察的生態及能力，不將魔力污染、迷宮製造或神祇創造等解釋寫成已知真相，也不賦予普通魔獸精靈專屬的神之秘法。

變體方向不構成通用強弱排序。具體能力、公會危險評級，以及較強變體能否計入某張狩獵委託，仍須按資料模型明訂，不能只根據名稱推論。

本篇的委託背景是可用的敘事示例，不構成已發生的世界事件、已上架委託或完整任務定義。正式委託須另外記錄階級、評級理由與結構化目標；區域狩獵和綁定清剿不能從背景文字推測。

圖片創作可使用核准的外觀與生活習性作為依據，但本篇不提供或宣告已有圖片資產。正式技能及生成流程落實後，才可宣告魔物已能在遊戲中按此設定運作。

本節於平衡核准後追加，不修改上文任何已核准範圍與使用邊界；上文所述「能力數值與公會危險評級於登錄中保持明示的空白欄位」已因平衡核准而改變，現況如下，上文文字不對應改寫。

§8 外部前置條件（一）「使用者平衡核准」——各變體完整能力數值（HP、MP、SP、物理戰鬥力、敏捷、
防禦、魔力）與最終公會危險評級——已於 2026-10-06 由使用者核准，範圍限於本篇首批十二個變體，以及據此
發布的正式狩獵委託。核准數值逐字登錄於 `world/lore/monster_species.py` 的變體登錄
（`monster-balance-profiles`），並由登錄建構期不變式檢查落在該變體宣告的層級區間內；本篇仍只承載
敘事，數值一律由登錄供給。

核准判準（設計理由，非再次推導）：每個數值都落在該變體宣告的層級區間；普通變體取該層級
`guild_rank_range` 下緣、較強變體取上緣；低階 HP 取區間下緣，因為創造預算角色的單次傷害面對
防禦 3–8 很小；中階數值調整為創造預算角色只能微量削血（防禦 12–20 對上該角色的攻擊），這正是
「一支普通冒險者隊伍」的意思；MP、SP 與 `magic_power` 維持 0，因為魔物魔法在任何地方都沒有文件，
每個層級的魔法區間刻意為 `(0,0)`，而六項特殊能力尚無可執行機制，資源池沒有消費者。

據此，本篇首批十二個變體的能力數值與公會危險評級已不再是空白欄位，而是逐字登錄的核准數值；其餘
物種的數值與評級仍未核准，欄位維持明示空白，且不得由名稱、描述或層級推測。

示例，不構成已上架委託：階級、評級理由與結構化目標仍須另行撰寫。六項特殊能力（氣流震穀、追隨燈光
