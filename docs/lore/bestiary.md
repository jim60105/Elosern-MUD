### 穗鳴雀

```bestiary

parent-species: sway_whistle_sparrow

    status: delivered
  - key: flock_leader

  - published_description_zh
  - published_appearance_zh
  - published_ecology_zh
  - habitat_tags
  - description_zh

```

**原型與棲地。**麻雀類的小型群居鳥，生活於東部平原的田埂、灌木與收穫後的農地。

**特殊生態。**啄食成熟穀物前，族群會發出短促而整齊的鳴聲，接著以微弱風屬性氣流震落乾燥穀粒。穗間響起的沙沙聲，是農民辨認牠們的線索。牠們造成的麻煩集中於收穫期；田地照常耕作，反覆造訪的族群則會損耗尚未收起的穀物。

**能力邊界。**牠們的氣流只震得動乾燥鬆脫的成熟穀粒，濕穀與牢固的未熟穗會留在穗上。這股氣流的力量集中在穗間，糧車與作物都保持原樣，影響範圍也只及於族群停留的一小片田地。近身時，牠會配合短促氣流啄擊，命中後使對手短暫分心；此招在任何地點都能使用，效果集中於被啄中的對手。

| 變體 | 核准方向 |
| --- | --- |
| 啄穗型 | 普通版本，分散覓食 |
| 領群型 | 以鳴聲協調同伴，從不同方向干擾驅趕者 |

**委託背景示例。**收穫已近尾聲，東側田區每天清晨仍有成群穗鳴雀來訪。農戶請公會處理持續侵入的族群，以免今年最後一批穀物留不下來。

**原型與棲地。**近岸蟹類，棲息於兩側海岸的礁隙、潮池與港外灘地。

**特殊生態。**背甲上的發光斑紋會追隨附近燈光的明暗節奏。沿岸居民知道牠們會聚集在魔法燈附近，漁人偶爾將牠們當成潮池的位置標記。大量聚集時，初次入港的小船可能誤判岸邊訊號；靠近礁洞的人也可能受到螯足攻擊。

**能力邊界。**牠們重現的是附近既有光源的節奏，斑紋的明暗始終對應真實燈光，周圍物體也保持本來面貌。牠會在螯擊時收緊甲殼，短暫提高自身防禦；這項動作在有光或無光處都能使用。發光斑紋專門呼應燈光，螯擊則是單純的近身攻擊。

| 變體 | 核准方向 |
| --- | --- |
| 灘行型 | 普通版本，遇人多半退避 |
| 守礁型 | 占據狹窄洞口，利用地形保護族群 |

**委託背景示例。**港外的候船燈附近聚集了一批潮燈蟹，已有夜歸小船認錯泊岸方向。碼頭請公會清理這處聚集地，恢復燈號辨識。

**原型與棲地。**穴居兔類，生活於平原邊緣與丘陵的鬆土帶。

**特殊生態。**牠們以土屬性力量壓實巢壁，將挖出的土築成低矮環埂。居民從環狀排列、異常牢固的小土埂辨認巢穴；這些土埂能撐過普通雨水，因此棄置巢穴也會留下痕跡。族群沿灌溉渠築巢時，土埂可能堵住分水口，坑洞則妨礙農具與牲畜通行。

**能力邊界。**牠們的土屬性力量作用於巢穴周圍的鬆土，岩盤、城牆與石造基礎都保持完好。洞道是牠們逃離時一路奔跑穿過的通路。受逼近時，牠會以土屬性力量穩住身體後蹬擊，短暫提高自身防禦；此招在平地上隨時可用，效果只作用在牠自己身上。

| 變體 | 核准方向 |
| --- | --- |
| 掘巢型 | 普通版本，依靠洞道逃避 |
| 護巢型 | 加固入口，在窄處阻擋侵入者 |

**委託背景示例。**兩戶農家原以為渠水不足是分水爭議，查找後才發現分水口旁有築埂兔巢。公會受託處理占據渠岸的族群，讓灌溉恢復。

**外觀。**半透明膠體貼著濕地起伏，外膜浮著細緻泥紋。收膜時，泥粒聚成較深的環帶，撞擊留下的缺口隨著身體舒展露出濕亮膠質。

**生態與在地關係。**牠通常獨自行動，濕潤處可見數隻分散覓食。靠近的腳步會使牠縮向陰濕處；遭到逼近時，牠收緊泥膜護住身體，再以短距離撞擊自衛。聚集的個體將細泥帶到狹窄分水口，農人會疏通渠口並處理反覆停留的個體。牠的活動集中於保有水膜的陰濕地帶，護膜則由體表已附著的細泥形成。

**戰鬥中的表現。**遭到逼近時，牠收緊外膜，泥粒沿著體表聚成較深的環帶，短暫形成一層護膜；護膜維持一小段時間，牠再以短距離撞擊回應。

| 變體 | 核准方向 |
| --- | --- |
| 濕岸型 | 普通版本，貼著潮濕溝岸與滲水洞口覓食 |

**委託背景示例。**一處農家的狹窄分水口連日被泥膜史萊姆停留，渠水分注因此不順。農家請公會處理聚集在渠口的個體，讓灌溉恢復。

**戰鬥中的表現。**牠的翅鱗帶著微弱暗屬性力量。近身時，牠以厚重的翅膀撲打對手，撲中時抖落鱗粉，讓對手手腳短暫發沉、動作遲緩；鱗粉在撲中的那一下才大量抖落。
