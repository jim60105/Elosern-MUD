# Editorial review: 地標儀式文本（landmark-rite-content 與 landmark-rite-content-completion）

## 1. 審查結論與範疇

本文件記錄 `world/lore/rites/content/landmark_rites.yaml` 全數十個原型、二十個場景的逐項審查，審查日期為 2026-11-14。第一次交運（`landmark-rite-content`）撰寫 `spring`、`statue`、`megalith`、`tower`、`tree`；第二次交運（`landmark-rite-content-completion`）補上 `grave`、`mine`、`gate`、`cliff`、`plaza`，並把剩下七十六個行政區的暫定指派改成最終指派。範圍涵蓋每個原型兩個選項的 `self` 場景，以及一百二十個行政區的原型指派。同日另做一次用字與動詞搭配的校正，紀錄見第 8 節。

本審查為人工判斷的紀錄。聲調、用字、敘事節拍與情節品質由人閱讀判定，專案內沒有任何測試斷言這些內容；`world.lore.tests.test_rite_content_document` 只證明本文件能通過嚴格載入器，`world.lore.tests.test_rite_content` 只證明載入與安裝機制。場景行號以各場景 `lines` 序列的第一行起算。

審查同時確認了刻意留給後續變更的部分。每個選項的 `watch` 皆為 `null`（`landmark-rite-watch-perspectives` 另行撰寫）、每個原型只有兩個選項（第三選項屬 `landmark-rite-third-option`）。這兩次內容變更都沒有程式碼；文件由啟動時的 `load_published` 載入，沒有規則、面板、指令或照明程式碼，也沒有任何寫入圖鑑或探索紀錄的程式碼。

`exposure` 衡量身體在場景裡被誰看見、露出多少。沒有旁觀者、衣料完整者為 0；衣料被掀開、濕貼或推開而露出輪廓與皮膚，或身體進入風、水與光線所及的半開放處者為 1；身體在開闊處或眾人的目光裡露出大片者為 2。`grave` 的兩個選項都在墓碑旁完成、沒有旁觀者，`mine` 的坑口與窄道裡沒有旁觀者，只有回音，因此皆為 0；`gate.trade` 的裙襬被掀到腰上、`cliff.bathe` 的濕衣貼住全身，定為 1；`cliff.lean` 的裙襬整片掀開、`plaza` 的兩個選項都在廣場的注視下進行，定為 2。前一版的 `tower.climb` 窗口毫無遮蔽，同樣是 2，`tree.rest` 躺臥落葉而樹冠最後讓開，比站立的 `tree.embrace` 高一級。

`shame` 依場景把身體交給誰、交得多徹底而定。只在石面、共振、鐘腔或坑道裡被觸及，身體還在自己手裡，或身處無人看見的林地者為 0 或 1；把整個人交給水、風、眾人的目光或死者的名字，或把痕跡留給門檻收下者為 2。差別在交出多少，`spring.drink` 只讓水面貼上嘴唇，`spring.wade` 整個人走進泉心，因此前者為 1、後者為 2；`cliff.bathe` 站在潭水裡被水柱沖刷而身體仍撐得住，維持 1，`cliff.lean` 把重心交給崖與風，定為 2。`grave` 的兩個選項、`gate.trade` 與 `plaza` 的兩個選項因此也都是 2，前一版的 `statue` 兩個選項與 `tower.climb` 同樣落在 2。
