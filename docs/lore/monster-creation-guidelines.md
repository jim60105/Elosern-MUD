# 魔物創作傾向指南

本篇規範伊洛瑟恩魔物的創作與審查方式，供物種設定、討伐委託背景與外觀設計共同參照。核心方向是**以讀者熟悉的動物或傳說生物為原型，透過伊洛瑟恩的魔法、生態與生活環境，形成具有地方特色的魔獸**。

**核准日期：**2026-10-05。創作準則已核准；本篇不核准任何個別物種，也不宣告物種名錄或生成機制已實作。首批物種創作集中於低階與中階，高階與災厄物種不屬於首批內容。

世界背景請搭配 [世界觀總覽](/lore/overview) 閱讀，能力與魔法邊界請參照 [魔法技能體系](/lore/magic-system)。

物種、變體、個體與委託的資料責任，另見 [魔物資料模型設計](/superpowers/specs/2026-10-05-monster-data-model-design)。該設計已核准，尚未實作，也不取代個別物種的內容審查。

已通過內容核准的首批物種，另見 [魔物圖鑑](/lore/bestiary)。圖鑑記錄核准範圍，本指南繼續適用於後續候選與變體創作。

## 設定依據與核准邊界

本指南以原始世界觀設定 `tmp/story_settings/world_info.md` 為創作依據，並對照現行世界觀與魔法文件。原始設定明訂日式劍與魔法世界、輕鬆冒險基調，以及日常與冒險並重；大陸的農業、採礦與海岸貿易都能持續運作。魔物創作必須保留這些生活條件。

分級資料中的種名只作為威脅層級的舉例，不構成正式物種名單。測試資料、程式中的既有名稱與未核准提案，都不能取代個別物種的內容審查。

本指南適用於新候選及未經正式核准的既有候選。任何物種都須先通過下列創作審查，再定義戰鬥設定、公會評級與圖片需求。

## 1．原型容易辨認，特殊性必須影響生活

優先使用現實動物、民間傳說與常見奇幻生物的原型。輪廓、移動方式與基本行為應容易理解，讀者不必先閱讀長篇設定才能辨認眼前的生物。完全新創、缺乏熟悉原型的幻想物種，不作為日常魔物的主要方向。

直接套用傳統怪物圖鑑會缺乏世界辨識度；大量創造全新奇獸會增加理解負擔。因此，創作時保留容易辨認的原型，讓牠在伊洛瑟恩的生活方式產生具體差異。

差異不能只靠改名、換色或加上「魔」「巨」「鐵甲」。特殊性應至少影響棲地、覓食、築巢、群體行為或與居民的關係，並能從外觀或行為觀察到。

改名後仍只是普通動物，特色不足；全身充滿難以理解的器官與能力，則超出本指南的創作方向。

## 2．魔法特色集中，能力有可理解的限制

低階與中階魔獸以一項主要異常能力為核心，其他特徵配合它發展。擅長伏擊的能力，應與牠的棲地、感官及捕食方式相容，不能只是為戰鬥追加的任意招式。

元素能力沿用既有八屬性框架，實際效果遵循現行魔法設定。不能因為是魔獸，就任意取得所有屬性的優點，也不預設所有魔獸都會施法。描寫能力時，須交代可使用的情境與限制，讓居民及冒險者能形成合理的應對方式。

普通魔獸不具備精靈專屬的神之秘法。時間、空間與世界規則的干涉，不用來製造日常討伐的新鮮感。魔法作用與神性資格以 [魔法技能體系](/lore/magic-system) 及其連結的現行系譜為準，不從舊分級舉例推導新的能力權限。

## 3．描寫可觀察的生態，保留真正起源的謎團

原始設定將魔獸記為「自然生成，成因未知」，也將魔獸與迷宮的真正起源列為未解之謎。因此，可以詳述魔獸出現在哪裡、如何生活，以及對環境魔力有何反應。

不得將「所有魔獸都是普通動物受魔力污染而變異」「迷宮會製造魔獸」或「諸神創造魔獸」寫成已知真相。這些解釋會提前決定世界的重要謎團。居民的傳說、學者的猜想與可觀察事實須分開標示，不能藉由物種敘述把猜想升格為正典。

迷宮與諸神、精靈之間的關聯屬於設定中的隱秘真相，不能預設一般居民或公會都知情。生活習性可以詳實，起源解釋必須克制。

## 4．特色要與大陸的具體生活有關

每種魔獸都應與至少一項既有世界設定形成具體關係。只提供一個戰鬥技能，無法說明牠為何屬於伊洛瑟恩。

| 既有世界設定 | 可以發展的魔獸關係 |
| --- | --- |
| 東部平原的農業 | 作物、灌溉、糧倉與農地邊界造成的人獸接觸 |
| 西部丘陵的礦業與工藝 | 礦坑、岩層、廢棄工事與匠人對素材的認識 |
| 西北高地的狩獵與部族文化 | 季節性獵場、群體行為、成年禮與獵人禁忌 |
| 海岸貿易與遠洋魔獸 | 近岸航路、漁場與船員對危險水域的判斷 |
| 迷宮與神代遺跡 | 特殊環境中的適應與異常現象，保留成因的不確定性 |

上述關係是創作線索，不是新物種或新社會習俗的核准名單。具體內容仍須符合世界設定並接受審查。

部分魔獸掉落結晶是原始設定中的既有現象，但不代表每種魔獸都必須具備可採集素材。本指南也不擴充完整的生產系統。

## 5．魔獸造成地方問題，世界仍能正常生活

伊洛瑟恩的基調是輕鬆冒險，城鎮治安良好，農業與貿易持續運作。普通魔獸應造成局部、可處理的問題，不讓居民每天生活在滅絕危機中；過度黑暗、沉重或以獵奇恐怖為主要賣點的設定，不作為日常魔物的創作方向。

威脅可以來自護巢、爭食、遷徙或占據人類設施，無須每種魔獸都天性邪惡、見人就殺。討伐委託的背景應說明當地發生的具體衝突，避免反覆使用「附近有怪物，請殺掉」作為全部動機。

城市及有人維護的生活區域，與偏遠荒野、巢穴或迷宮之間的危險差異，需要合理的地區設定。不能只因玩家進度提高，就讓原本安全的城市周邊充滿高階魔獸。

危險程度由棲地、能力與遭遇配置決定，不隨玩家進度提高。物種的個體危險度與整份委託的難度分開描述，不能把分散狩獵與一次遭遇的群體圍攻視為相同風險。

## 6．尊重既有智慧種族與精靈的特殊地位

人類與獸人友好且無種族歧視。動物型魔獸與獸人必須明確區分，不能把外形相近的獸人當成可討伐的怪物。

具有語言、聚落與完整社會的「人形怪物」，可能引入新的智慧族群及政治關係，須另行審視，不能當成普通物種順帶加入。熟悉的傳說原型也不免除此項審查。

精靈的稀少與超常地位必須保留。魔獸特色不能大量依賴精靈血液、神性或失落秘法，也不能將精靈當成所有異常生物的通用起源解釋。

## 7．命名在生態設定之後

先決定原型、特殊習性與地方關係，再命名。名稱應反映居民能觀察到的特徵，讓讀者能推測牠的外觀或行為。

不先取一個華麗名字，再追加能力使名字成立；也不靠元素前綴大量複製同一物種。具名變體應有生活或戰鬥上的理由，不能只是換色加數值。

物種與變體分開整理，不能把同一物種的普通、精英與首領版本當成不同物種湊數。名稱與外觀的變化不會自動成立新的物種身分。

## 候選物種審查

每個候選須完整回答下表，再進入正式物種選擇。審查只依創作內容判斷，不以測試資料或已有程式名稱作為核准證據。

| 審查項目 | 必須回答的問題 |
| --- | --- |
| 熟悉原型 | 讀者能辨認什麼動物或傳說生物原型？ |
| 特殊生活方式 | 哪項特徵讓牠有別於一般版本，且如何影響生活？ |
| 世界關係 | 牠與伊洛瑟恩哪項既有設定有具體關係？ |
| 能力邊界 | 異常能力有什麼限制，是否侵犯神性或未解謎團？ |
| 地方衝突 | 居民為何與牠發生衝突，委託背景能否自然成立？ |

如果只回答得出「牠比較大、比較強」，就退回修改。候選通過創作審查並經核准後，再定義戰鬥設定、公會評級與圖片需求，不在選種時任意填入能力數值。

委託的評級理由與背景風味文字分開記錄。評級理由交代戰鬥風險，背景說明委託人的動機及當地事件；完成條件由結構化目標資料判定，不從背景敘述推測。
