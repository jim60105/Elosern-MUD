# Design

## Context

The browser model retains raw x/y alongside lattice col/row and `cellSize`. Grid coordinates are metres; wilderness x/y are one-kilometre cell indices (`WILDERNESS_KM_PER_CELL=1` in the existing provider). Raw grid cross-layer targets are synthetic `_free_slot` positions. The projection must use raw same-layer coordinates and ignore col/row/cell, leaving the overlay model unchanged. Approved design §3–§5 and §6.3 define the algorithm.

## Goals / Non-Goals

Deliver the complete pure projection API with executed tests. Production renderer wiring belongs to the next change. No Vue, DOM, server geometry, new payload field beyond predecessor gateway, manual zoom, graph redesign or world-map data.

## Decisions

Create `web/webclient-app/lib/minimap_projection.js`. Accept nodes/edges, previous level or null and canvas constants; the integration caller supplies previous=null on a changed node-id map key. Return `{mode, level, nodes:[{id,x,y,tier,gateway}], exitStubs:[{bearing,label,action}], grid, scaleLabel}` exactly as the approved contract. Current is at 120,120. Export or centralize R_MIN=36, R_MAX=88, the 17-level ladder and default 100 in this module so tests and renderer consume one definition.

Determine the layer prefix and map key from the current canonical node ID, using the existing ID grammar. Work only on same-map/same-layer drawable nodes. Remembered remote nodes remain with the existing edge-marker path. One-hop exits are endpoints of labelled edges incident to current, even with null action; unlabeled star edges supply context only. Cross-layer targets generate stubs and never distances. A city-side stub obtains leads_to from the current gate metadata, a wilderness return stub from the grid target metadata. Use their existing renderer-local bearing, not a fictitious inter-layer distance.

Normalize same-layer differences to metres in this client-only projection. Wilderness deltas multiply by 1000 under the existing fixed one-kilometre coordinate-frame contract; grid deltas remain unchanged. This is a unit conversion, not a new independently configurable geography constant. Do not parse localized legend prose, change the provider, add transport fields or rewrite payload x/y. Unit tests must prove cardinal/diagonal distances of 1000/sqrt(2)*1000 and level 2000, so a mistaken raw-cell scale fails.

Select the smallest fitting ladder level, retaining prior only if it fits and is at most one step coarser. Reset is controlled by current map key, not the full current-node ID, so ordinary moves retain hysteresis. Use context distances when there are no exits; no positive distance selects 100. Compression is triggered strictly below R_MIN or above ladder capacity. Positive equal distances in compressed mode use radius 66. Use the approved logarithmic mapping for positive exits, linear inner mapping for context. Exclude zero values from logarithm/divisor selection; zero-distance exits receive deterministic north-first evenly spaced bearings and radius R_MIN to keep markers clear. If all exits are zero, default level and finite radius placement still apply. These are deterministic numerical resolutions of §3.5, with no new gameplay meaning.

Resolve similar-radius overlaps symmetrically around the circular mean bearing, bounded to ±20 degrees, using actual marker footprints from existing geometry constants or an explicit passed footprint. All unaffected bearings stay exact. Do not promise an unbounded arbitrary number of coincident exits can fit inside that angle; test the approved fixtures and representative coincident pairs with the stated cap. Context uses the chosen mapping and is omitted outside the canvas. Return bounded uniform dot spacing/anchor offsets from integer world multiples of M/5 and readable compressed ring distances placed through the same radial mapper. Rings outside the canvas are omitted; no dot-per-metre allocation.

## Risks / Trade-offs

Zero distances require an explicit finite policy. The previous level for an over-capacity compressed result is the coarsest ladder level, so the next call remains valid; mode still selects compression when required. Context-only mapping uses the same positive-distance policy with context as the scale candidates. Label fitting remains renderer-owned and never changes canonical coordinates.

The modified wilderness-legend requirement narrowly permits this projection-only unit conversion while preserving provider-derived legend generation and its patchability tests. It does not create a configurable client geography scale, duplicate localized note construction or expand the node payload.

Cases cover all constants, worked examples, strict threshold boundaries, previous-level keep/reset, zero/no-exit/context-only/equal-distance inputs, exact bearings, monotonic mapping, bounded spreading, cross-layer exclusion and stub action identity, map-key reset through the caller helper, dot anchors under movement and readable rings. Reuse an existing Python evidence module for a single executed-file wrapper and real traceability annotations. Use agent-browser to inspect retained `World/LocalMap` stories as unchanged-renderer controls; this pure slice must not claim the visual auto-scale cutover is already wired.
