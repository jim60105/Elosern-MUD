# Spec Delta

## ADDED Requirements

### Requirement: Sleep blocks acting purposes without removing authenticated authority
Sleeping bodies SHALL fail casting, item use, practice booking and other acting preflight with a stable sleep reason and zero effects/time. Authenticated status, lawful organizing, recovery and contextual control selection SHALL remain accessible. Browser and text SHALL enforce the same rules.

#### Scenario: Sleep cannot act
- **WHEN** a forged direct cast or item request names a sleeping member
- **THEN** server preflight rejects without costs, effects or time even if the UI allowed submission

#### Scenario: Organizing remains lawful
- **WHEN** an awake controller organizes a sleeping companion's bag through an existing lawful operation
- **THEN** sleep alone grants no extra restriction or time cost; the sleeper performs no action
