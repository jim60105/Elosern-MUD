## ADDED Requirements

### Requirement: The guide distinguishes allocation point caps from stat spans
The player-preset guide SHALL explain that presets use the same allocation policy as custom characters of their race and that an elf magic point is converted rather than added directly.

#### Scenario: An author derives the point budget
- **WHEN** the author follows the allocation example
- **THEN** it uses the shared starting profile and identifies the axis point cap, the exact budget and the magic conversion for elves
