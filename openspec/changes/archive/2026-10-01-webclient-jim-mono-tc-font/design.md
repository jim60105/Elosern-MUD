## Context

See proposal.md (Why). This change builds on two others.

- **Upstream v0.1.0.** The release `-web.zip` cuts each style into `latin`, `icons`, `cjk-common`,
  `cjk-big5`, and 2,500-code-point `cjk-N` slices: latin 87 KB, icons 1.37 MB, CJK 128 KB–1.6 MB. Its
  `build-web.py` subsets from the finished OTF with `layout_features=['*']`, so `calt` survives, and
  `verify.py --partial` already checks cell widths and shaping per slice.
- **Measured on the v0.1.0 OTFs** (fontTools): CFF, upem 2048, one cell 1233, CJK 2466, hhea
  1901 / −483 / 0 (same as Hack), GSUB `aalt calt frac locl ordn sinf subs sups`, no Reserved Font
  Name. Box drawing is Nerd Fonts' (U+2500–259F overwritten): `│` (536, −530, 696, 1950), `█`
  (0, −512, 1233, 1950), past the line box on both ends.
- **Trial re-slice** of Regular / Bold in the scratchpad, along the plan in D0:
  - latin 19.0 / 19.4 KB, latin-ext 18.8 / 20.8, greek-cyrillic 30.5 / 30.4, box 3.3 / 3.4,
    symbols 28.0 / 27.3;
  - CJK along the 105 Noto Sans TC weight-400 ranges of `styles/fonts.css`: 93 non-empty slices per
    weight, 13,283 code points, 1.8–48.9 KB each, about 2.9 MB per weight.
- **`webclient-map-label-cell-budget`** made the map geometry budget text in monospace cells from
  `web/webclient-app/lib/mono_cells.js`, generated by `tools/gen_mono_cells.py` from the Hack manifest's
  one-cell set.
- **The current Hack wiring** (archived change `2026-09-30-webclient-hack-mono-font`):
  - `fonts-hack.css` is imported by `main.js` and `.storybook/preview.js`, and `--f-mono` is
    `"Hack", "Noto Sans TC", monospace`;
  - `test_vue_typography.test_keycaps_and_command_input_keep_monospace` checks the rendered face
    through CDP `getPlatformFontsForNode`, with a `rendered_fonts` helper that pierces the textarea's
    UA shadow root and loads faces before querying;
  - `test_vue_foundation._assert_only_needed_hack_slices` strips Vite's `-<8-char hash>` suffix and
    asserts that only `hack-regular.latin` of the non-hot slices is fetched;
  - the requirement ID is traced from those two browser methods, two lattice methods, and the Hack
    contract test.
- **Jim Mono TC metrics.** Latin advance 0.602 em, CJK advance 1.204 em, and the same vertical metrics
  as Hack (`line-height: normal` ≈ 1.164 em). CFF outlines, unhinted slices. `calt` carries 29 ASCII
  ligatures.
- **Monospace consumers in HTML.** CJK there gets 20% wider:
  - the command line (`CommandLine.vue`);
  - `DockMenu.vue:585/821`;
  - `LocalMap.vue:378/406`, with `letter-spacing: .04em` at `:344`, which also suppresses ligatures
    there;
  - `MapOverlay.vue:299`;
  - `MessageWindow.vue:1158` (map art);
  - `FullLogOverlay.vue:516`;
  - `HelpOverlay.vue`;
  - `ParticipantFrame.vue`;
  - `PartyStrip.vue` (weight 700, ASCII only).

## Goals / Non-Goals

**Goals:**

- One bundled family draws all monospace text, with CJK at exactly two cells in both weights.
- No HTML surface clips, and no map geometry assertion is loosened.
- The Hack pipeline is fully removed.
- The imported assets are byte-reproducible from one pinned, checksummed release asset.

**Non-Goals:**

- Cutting fonts in this repository. Slicing lives upstream (D0); this repository only imports.
- Italic faces, Nerd Fonts icons, and CJK beyond the Noto Sans TC web coverage.
- Map geometry. That is `webclient-map-label-cell-budget`.
- Preload. It stays a non-goal: Vite hashes the URLs.
- Disabling ligatures anywhere. The owner keeps them. `letter-spacing` surfaces keep the browser's
  default behavior.

## Decisions

### D0. Upstream release contract (JimMonoTC repository)

The owner changes `scripts/build-web.py --split` in JimMonoTC and publishes a release (planned as
v0.2.0). This change consumes that release and pins it. The contract this repository relies on:

- **Asset.** `JimMonoTC-<ver>-web.zip`, listed in the release's `SHA256SUMS.txt`, holding
  `JimMonoTC-<ver>-web/JimMonoTC-<Style>.<group>.woff2`, `JimMonoTC.css`, and `licenses/**`
  (`LICENSE` OFL 1.1, `NOTICE.md`, `Hack-LICENSE.txt`, and the rest).
- **Groups per style**, disjoint, together covering the style's cmap:
  - `latin`, `latin-ext`, `greek-cyrillic`, `box`, `symbols`: the one-cell, non-private-use code points,
    first-claim over the five windows the Hack slices used;
  - `icons-<N>`: private-use Nerd Fonts icons, chunked;
  - `cjk-<N>`: two-cell code points inside Noto Sans TC's Google frequency range `N` (the ranges are
    vendored upstream as a data file), first claim in index order, empty ones omitted;
  - `cjk-x<N>`: the remaining two-cell code points in code point order, chunked.
- **Bounds.** Every woff2 file is at most 65,536 bytes. `build-web.py` fails the build otherwise.
- **Properties.** Slices are unhinted CFF; `calt` and its ligature glyphs stay in `latin`;
  `verify.py --partial` passes on each slice.
- **Box drawing.** Upstream `verify.py` gains an edge check on the master font: `─ │ ┌ ┐ └ ┘ ├ ┤ ┬ ┴
  ┼` reach their cell edges (left x ≤ 0, right x ≥ 1233, bottom y ≤ −483, top y ≥ 1901, per glyph as
  its arms require). A failure is fixed in the font, not relaxed here.
- **CSS.** `JimMonoTC.css` has one `@font-face` per file with family `"Jim Mono TC"`, the style's
  weight and style, `font-display: swap`, and its `unicode-range`.

*Alternative:* cutting slices in this repository from the OTF zip (a fontTools generator here).
Rejected by the owner: the font's own release should serve the web directly.

### D1. Import tool `tools/import_mono_font.py`

- **Inputs.** Module constants pin the release URL and SHA-256 (from `SHA256SUMS.txt`). Standard
  library only (`urllib`, `hashlib`, `zipfile`, `re`, `json`, `unicodedata`), run as
  `uv run --locked python -m tools.import_mono_font`. Network access is needed only to regenerate; a local copy of the
  asset may be passed as the only argument instead, and its SHA-256 is verified the same way.
- **Selection.** Styles `Regular` (400) and `Bold` (700). Groups `latin`, `latin-ext`,
  `greek-cyrillic`, `box`, `symbols`, and `cjk-<N>` with a numeric `N`. `icons-*` and `cjk-x*` are
  dropped. File names are kept verbatim.
- **CSS.** The release CSS is parsed into rules. Kept rules are re-emitted in release order with
  `src: url(../fonts/jimmonotc/<file>) format('woff2')`; every other property is copied unchanged. A
  header names the tool, the release, and the OFL. The output is `styles/fonts-mono.css`.
- **Manifest** `fonts/jimmonotc/codepoints.json`, derived from the kept rules' `unicode-range`:

  ```json
  {"release": "v0.2.0", "regular": [...one-cell...], "bold": [...one-cell...],
   "cjk": {"regular": [...], "bold": [...]}, "noto_wide_missing": [...]}
  ```

  `noto_wide_missing` is the East Asian Wide/Fullwidth code points (`unicodedata`) inside the Noto
  Sans TC weight-400 coverage parsed from `styles/fonts.css` that no kept `cjk-<N>` slice declares.
- **Fatal checks before writing:** a kept file over 65,536 bytes or not starting with `wOF2`; a kept
  file missing from the CSS or a CSS rule without a file; overlapping ranges within one weight;
  `cjk.regular != cjk.bold`; an arrow or other ASCII code point outside `latin`; a missing
  `licenses/LICENSE`.
- **Output.** The tool clears `fonts/jimmonotc/`, then writes the slices, `codepoints.json`,
  `licenses/**`, and `fonts-mono.css`. A second run is byte-identical.
- **Tests.**
  - `tests/test_mono_font_import_tool.py` (no network): CSS parse and rewrite on a synthetic sheet,
    group selection, range parsing, overlap rejection, and the manifest on a synthetic zip built in the
    test.
  - `tests/test_mono_font_contract.py` (committed files): URLs resolve and every file is referenced;
    `wOF2` magic and the 64 KB bound; disjoint ranges per weight whose union equals one-cell ∪ `cjk`;
    `cjk.regular == cjk.bold`, with the count pinned to the imported value; the CJK union equals the
    East Asian Wide/Fullwidth code points of the Noto weight-400 coverage minus `noto_wide_missing`
    (so every declared CJK code point lies in that coverage, and `noto_wide_missing` is disjoint from
    `cjk`); no private-use code point declared; the licence files; and the exact `--f-mono` stack (D6).

### D2. Wiring and stack

- **Imports.** `main.js` and `.storybook/preview.js` import `./styles/fonts-mono.css` where
  `fonts-hack.css` is imported today.
- **Stack.** `tokens.css` sets `--f-mono: "Jim Mono TC", "Noto Sans TC", monospace;` and its comment
  states the two-cell rule and the Noto fallback.
- **Fallbacks.**
  - `Noto Sans TC` draws only wide code points outside the shipped coverage, at 1 em.
  - `monospace` draws code points in neither face, such as ⌨ U+2328 and ✕ U+2715. HelpOverlay's
    `--f-sans` routing for ⌨ stays.

### D3. The map cell table follows the face

`tools/gen_mono_cells.py`'s manifest constant changes from `fonts/hack/codepoints.json` to
`fonts/jimmonotc/codepoints.json` (`regular`). The table is then regenerated and committed.
`tests/test_mono_cells_table.py` byte-compares the regenerated table. Jim Mono TC's one-cell set is
Hack's plus the Nerd Fonts narrow extras, so the map budget becomes exact for the new face.

### D4. Removing Hack

Delete:

- `tools/gen_hack_font_slices.py`;
- `web/webclient-app/fonts/hack/`;
- `styles/fonts-hack.css`;
- `tests/test_hack_font_slices_contract.py` and `tests/test_hack_font_slices_tool.py`.

The browser tests' Hack names change with D5.

### D5. Browser tests

- **Rendered face** (`test_keycaps_and_command_input_keep_monospace`). These report a custom font
  whose `familyName` starts with `Jim Mono TC`:
  - the first `kbd`;
  - `.cmdfield__prompt`;
  - the typed `look 42 看看` input.

  The input reports no non-custom font and no `Noto Sans TC`. `rendered_fonts` preloads
  `16px "Jim Mono TC"` instead of Hack.
- **Cell advances**, a new method `test_monospace_cells_are_exact`. `.github/browser-shards.json`
  already owns `VueTypographyBrowserTest` by its class label, so the new method is owned without an
  edit (a method label would overlap the class label and fail the ownership contract).
  - It renders the populated-HUD story and appends one probe `<span>` per run to `document.body` with
    `font: <weight> 20px/1 var(--f-mono); white-space: pre; font-kerning: none; font-synthesis: none`,
    once at weight 400 and once at 700. Synthesis is off so a missing bold face cannot pass as bold.
  - After `document.fonts.load` of `<weight> 20px "Jim Mono TC"` with all probe text, it measures each
    span's whole `getBoundingClientRect` width (never a sub-range inside a ligature) and requires a
    loaded Jim Mono TC `FontFace` at that weight.
  - It asserts, within 0.5 px:
    - `MMMM` = 4 × 1233/2048 × 20 px;
    - `看看看看` = 2 × `MMMM`;
    - `……──` = `MMMM`;
    - `->==` = `MMMM`, the ligature run.
  - CDP reports only Jim Mono TC (custom) for every probe in both weights.
  - The probe goes on `document.body` through `page.evaluate`, not on `#storybook-root` or through a
    `.locator()` hook: the frozen-contract scan flags any selector literal in browser tests, and the
    tokens resolve from `:root` anyway.
- **Offline slices** (`test_vue_bundle_loads_from_origin_offline`).
  - The helper becomes `_assert_only_needed_mono_slices`.
  - The expected names are `JimMonoTC-Regular.latin`, `JimMonoTC-*.greek-cyrillic` and
    `JimMonoTC-*.latin-ext`, after stripping Vite's `-<8-char hash>` suffix.
  - The weight-400 wait uses family `Jim Mono TC`.
- **Stale Storybook.** `.storybook-out` is deleted and rebuilt before these runs, as in the Hack change.

### D6. `--f-mono` contract

The `--f-mono` exact-stack check moves from the deleted Hack contract into
`tests/test_mono_font_contract.py`.

### D7. HTML surfaces

The focused shell and command-line tests and the D9 screenshots are the oracle.

- A surface whose monospace CJK now clips or wraps is fixed in its own CSS, by ellipsis, `min-width`,
  or a wider token-driven box, never by shrinking type below the chrome floor.
- Each fix is listed in the apply summary. The expected candidates are the command-line field and
  `.local-map` detail rows. Map SVG is covered by the geometry change.

### D8. Traceability

`tools.spec_traceability` indexes only `openspec/specs/`.

- **Before archive.** The branch keeps the Hack ID on the kept tests: the two browser methods and two
  lattice methods. The Hack requirement still exists in the main spec until the sync, so
  `spec_traceability check` passes.
- **At archive**, in the same commit as the spec sync:
  - the Hack ID is replaced by
    `webclient-vue-application::the-monospace-type-role-is-a-self-hosted-sliced-jim-mono-tc-face` on
    those four methods;
  - the new ID is added to `test_monospace_cells_are_exact` and to every method of
    `tests/test_mono_font_contract.py`.

  Task 3.4 runs `check` on the branch, and task 7.1 runs it after the sync.

### D9. Visual verification with agent-browser

- **Capture.** Reuse the Hack change's capture script: 11 Storybook surfaces at 1440×900 and
  1280×720, before and after. Add a Playwright headless-shell render of the box grid, warm and
  throttled cold.
- **CJK grid probe.** A scratchpad probe page, served over HTTP from the built Storybook's assets,
  draws `┌────┐ / │北門│ / └────┘` and a four-row CJK/ASCII grid in `var(--f-mono)` at the map-art size.
  No fixture in the repository is a well-formed CJK grid: the `core.js` fixture's rows differ in cell

- **Checks:**
  - grid strokes join;
  - CJK columns align;
  - `── 稱號冊 ──` headings;
  - the command line with `look north 看看 42`;
  - ligatures only where ASCII sequences form them;
  - the cold-cache swap.

## Risks / Trade-offs

- **[HTML monospace CJK is 20% wider]**
  - Mitigation: the D7 oracle and fixes in this change.
- **[First paint of CJK map labels waits on Jim Mono TC slices instead of already-cached Noto Sans TC
  slices]**
  - Mitigation: `font-display: swap`, the same frequency split, and the D9 cold-cache check.
- **[Ligatures in player input and game text]**
  - `->`, `==`, `//`, `??`, `::` and `||` render as ligatures of the same width.
  - This is the owner's choice. D5 proves the width is kept.
- **[CJK outside the coverage falls back to Noto Sans TC at 1 em]**
  - Rare characters misalign in grids.
  - The map budget counts them as 2 cells (≥ 1 em), so layout stays safe.
- **[`index.css` grows by about 200 `@font-face` rules]**
  - Each is a few hundred bytes, and the small slices are inlined as data URIs.
  - This is comparable to the existing families' 634 rules.

- **[The upstream release is not published yet]**
  - Task 1.1 blocks until the release exists and meets D0. The import tool's fatal checks catch a
    release that drifts from the contract.
- **[About 6 MB of new repository bytes]**
  - A page downloads only the slices it draws.
  - Bold CJK is about 2.9 MB and has no bold-CJK consumer today; the only bold monospace text is the
    ASCII combat badge. The owner decided to keep it, so bold CJK stays two cells if it ever appears.
- **[Nerd Fonts box glyphs differ from Hack's]** The upstream edge check (D0) guards the geometry, and
  D9 guards the render.

## Migration Plan

This lands after `webclient-map-label-cell-budget` and the upstream release. It ships as the feature
commits plus the archive-time traceability commit. Rollback is a revert. A later font release is a
constant bump plus a re-run of the import tool.
