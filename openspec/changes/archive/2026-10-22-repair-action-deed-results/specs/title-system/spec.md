# Spec Delta

## ADDED Requirements

### Requirement: Authorized adult result families survive aggregation
Authorized adult effects, transitions, counter changes and resistance outcomes SHALL survive selection and aggregation with their supporting source IDs. Own-state permission SHALL NOT disclose another participant's internal state. An action's attached milestones SHALL count with that occurrence before repetition compression.

#### Scenario: Own adult outcomes reach the rendered feed
- **WHEN** a real adult action commits authorized transitions, counter changes and effects alongside a resistance verdict
- **THEN** the rendered material retains each authorized result family and its actual roles without substituting milestones for ordinary outcomes

#### Scenario: Other participant state stays absent
- **WHEN** another participant has different private counters or milestones unknown to the player
- **THEN** those fields affect neither the player's rendered facts nor aggregate counts

#### Scenario: Attached milestone is not a separate action boundary
- **WHEN** consecutive matching action occurrences have a milestone attached to the first action and no independent intervening occurrence
- **THEN** compression retains both actions and the milestone with count two and all supporting sources
