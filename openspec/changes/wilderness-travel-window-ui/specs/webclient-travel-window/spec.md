# Spec Delta

## Purpose

Replace the temporary node adapter with the shared run-length decoder and display live sight, phase tint and disclosed annotations. This capability defines observable browser travel behavior and its data boundaries.

## ADDED Requirements

### Requirement: Travel consumes the shared current wilderness window
Travel presentation SHALL consume the existing validated run-length wilderness window through the shared decoder, preserve unknown-data privacy and recover from stale maps only on a correlated complete current adoption.

#### Scenario: Decoder and clean cutover
- **WHEN** synthetic runs include frame padding, sparse visited/action nodes, malformed totals and unknown extra metadata
- **THEN** both map consumers share decoded coordinates and rejection behavior, node-form wilderness is no longer accepted and no action or fact is invented

#### Scenario: Disclosure-only annotations
- **WHEN** revealed, unknown, hidden and live/memory cells include display metadata and entity threat facts
- **THEN** only permitted annotations render, unknown runs remain minimal and hostiles or names never appear from memory or private source keys

### Requirement: Travel observations follow canonical sight and phase facts
Travel presentation and structured notices SHALL use canonical current phase and sight observations for tint, edge cards and new-sighting or light-boundary events without recomputing visibility rules in the browser.

#### Scenario: Sight transitions
- **WHEN** canonical observation identities enter, remain or leave live/distant sight across synthetic moves
- **THEN** newly present observations emit once with permitted names, stable materialization does not resight and bearing cards acquire no exact target

#### Scenario: Phase interval and read isolation
- **WHEN** a positive committed move/skip crosses dusk/night entry, a zero-charge move occurs and snapshots repeat
- **THEN** ordered boundary notices publish only for committed crossings, supplied phase drives tint and reads advance no time
