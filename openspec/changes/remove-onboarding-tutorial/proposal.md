# Proposal: remove-onboarding-tutorial

## Why

The onboarding subsystem (guided South Gate tutorial run by the `onboarding_guard` NPC) cannot survive the planned race-based starting cities without being duplicated per city, which is unacceptable cost. The approved design (`docs/superpowers/specs/2026-09-04-onboarding-removal-one-way-limbo-design.md`) retires the whole subsystem: onboarding meaning shrinks to "reading the author's static teaching material inside 虛境 (Limbo) before leaving", and the guard NPC — the last production NPC without authored identity — dies with it, closing the NPC-identity invariant (D7a exemption) automatically.

## What Changes

- **BREAKING** **DELETE** `world/rules/onboarding.py` and the `world/onboarding/` package outright (state machine, guide tables, scenes, `sync_guard_npc`, `relocate_to_starting_location`, `maybe_play_arrival`, `observe_room_entry`, `set_onboarded`, `run_scripted_talk`). The South Gate guard NPC dies with the sync step: remove `sync_guard_npc` from `server/conf/at_server_startstop.py` and `STARTUP_STEP_ORDER`. Clean cutover — zero migrations, zero compat shims (unreleased project, zero users).
