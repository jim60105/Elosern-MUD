## 2. The translation seam

- [ ] 2.1 Create `world/art/translate.py` with a module docstring stating the boundary: a local pre-process on the claimed `source_description`, applied between the record read and the sd-webui client call, for every subject kind; it raises and never logs (the worker owns the events). Define `TranslateError(Exception)` carrying `.code`, mirroring `SDError` and `CutoutError`.
- [ ] 2.2 Implement the language gate: `needs_translation(line) -> bool` is true when the line carries at least one Han character. Reuse the CJK Unified Ideographs range check already written in `world/lore/settlements/_prose_lang.py::_is_han` — either import it or restate it with a comment naming that module as the precedent, but do not invent a third spelling of the same test.
- [ ] 2.3 Implement `resolve_translate_backend()` (dotted-path import of `ART_TRANSLATE_BACKEND`, mirroring `resolve_cutout_backend`), mapping every resolution failure — non-dotted path, import error, missing attribute, constructor failure — to `TranslateError("art_translate_unavailable", ...)`.
- [ ] 2.4 Implement the module entry point `translate_description(text) -> tuple[str, TranslationCounts]` (or an equivalent single return carrying the counts): split on `\n`, select the Han-bearing lines, and **short-circuit before resolving a backend when none qualify** — returning the input identically with zero counts. This short-circuit is a requirement, not an optimization (delta spec, "A description in which no line needs translating SHALL short-circuit").
- [ ] 2.5 Call the backend once with the tuple of qualifying lines (`translate(lines) -> sequence[str]`, design D8), then validate the result BEFORE reassembly: not a sequence, wrong length, or a non-string element each raise `art_translate_error`. Map every other escaping exception from the call to `art_translate_error` too; nothing unbounded may leave this function.
- [ ] 2.6 Reassemble by substituting the translated lines back into their original positions and rejoining with `\n`, so line count and order are preserved exactly. Count the returned lines that still carry a Han character and report the count — do NOT treat them as failures (design D9).
- [ ] 2.7 Keep `world/art/translate.py` free of any `world.observability` import or call.
- [ ] 2.8 Create `world/art/fake_translate.py::FakeTranslator` mirroring `FakeCutoutBackend`: records every call, `fail_every_call` / `add_failure` script `TranslateError`s, and the success path applies a fixed, observable transformation that can never equal its input for a Han-bearing line (a marker prefix plus a transliteration-free placeholder is enough). It must import no translation library and make no network call.

## 3. Worker integration

- [ ] 3.1 `world/art/worker.py::_settle_one`: immediately after `description = str(record.db.source_description or "")`, when `settings.ART_TRANSLATE_ENABLED` is true, run the stage and replace the local `description` with its result. Do NOT write the result back to the record — `source_description` and `source_hash` stay authored text (design D2).
- [ ] 3.2 Wrap the stage call in its own `try/except TranslateError` that logs and falls back to the original `description` and then CONTINUES. It must not touch the existing settle mapping: no `art_translate_*` code may reach `settle`, `settle_gallery_failed`, or any record error field (delta spec, "Translation failure degrades the prompt and never costs the image").
- [ ] 3.3 Catch a non-`TranslateError` escaping the stage in the same arm and treat it identically — a degraded prompt, not a lost image. The stage is specified never to raise anything else, and this arm is the belt-and-braces that keeps that contract from being load-bearing on the job's survival.
- [ ] 3.4 Emit `art_translate_done` (info: `job`, `subject`, `image_id`, `lines_total`, `lines_offered`, `lines_untranslated`, `duration_ms`) and `art_translate_failed` (warn with `exc=`: `job`, `subject`, `image_id`, `code`) through named `world.observability` imports in `worker.py`. Emit NEITHER when the stage is disabled or short-circuited.
- [ ] 3.5 Verify by reading that the gallery path and the classic path share this insertion point — `_settle_one` handles both — so no second call site is needed.
